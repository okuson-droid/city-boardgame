## 第1章 ゲームの概要

### 1-0 総則

**1-0-1** プレイヤーは国王から新たな都市の開発を命じられた領主となり、5ラウンドにわたって自分の都市を発展させる。

**1-0-2** 土地を開拓し、建物を建設し、住民を増やし、経済・文化・軍事などの各分野を発展させることで、国王から高い評価を得ることを目指す。

**1-0-3** ゲーム終了時、都市の規模を示す基礎得点と、5つの評価軸による得点を合計し、最も高い得点を獲得したプレイヤーが勝者となる。

**1-0-4** プレイ人数：3～4人

**1-0-5** プレイ時間：未確定

**1-0-6** ラウンド数：5ラウンド

**1-0-7** ゲーム形式：ワーカープレイスメント

### 1-1 5つの評価軸

**1-1-1** 都市は以下の5つの評価軸で評価される。

1. 経済・産業
2. 文化・学術
3. 生活・福祉
4. 自然・環境
5. 軍事・防衛

**1-1-2** 各評価軸は独立した得点源であると同時に、隣接する評価軸の発展を間接的に支援する関係にある。

**1-1-3** 隣接関係は以下のとおり。

経済・産業 → 文化・学術 → 生活・福祉 → 自然・環境 → 軍事・防衛 → 経済・産業

**1-1-4** 評価軸同士の支援は、直接的な得点加算ではなく、資源・アクション・発展機会などを通じて表現する。

## 第2章 ゲームの準備

### 2-1 個人ボードと初期配置

**2-1-1** 各プレイヤーは個人ボードを1枚受け取る。

**2-1-2** 個人ボードは六角形マス45個で構成され、6行に配置されている。

| 行 | マス数 |
|---|---|
| A | 8 |
| B | 7 |
| C | 8 |
| D | 7 |
| E | 8 |
| F | 7 |
| 合計 | 45 |

**2-1-3** マスの座標は、上からA～F、各行の左から1～8で表す。

**2-1-3-2** 六角形マスは頂点が上を向く向きに置く。7マスの行（B・D・F）は、8マスの行（A・C・E）に対して左右両端とも半マスずつ内側に並ぶ。

**2-1-3-3** マスの隣接は以下のとおりとする。

- 同じ行では、列番号が1違うマス同士が隣接する。
- 7マスの行の j 列目は、上下に隣り合う8マスの行の j 列目と j＋1 列目に隣接する。

**2-1-4** 初期開拓済みマスはE1・F1とする。

**2-1-5** 地形の内訳は以下のとおり。

| 地形 | マス数 |
|---|---|
| 水場 | 7 |
| 山岳 | 7 |
| 平原 | 16 |
| 森林 | 15 |
| 合計 | 45 |

**2-1-6** 地形と色の対応は以下のとおり。

- 平原：黄色
- 森林：緑色
- 山岳：灰色
- 水場：水色

**2-1-7** 初期開拓済みマスE1・F1は森林とする。

### 2-2 初期資源

**2-2-1** 各プレイヤーは以下の資源を受け取る。

| 項目 | 初期値 |
|---|---|
| 金 | 0 |
| 資材 | 5 |
| 金の生産力 | 20 |
| 資材の生産力 | 3 |
| 通常ワーカー | 5人 |
| 臨時ワーカー | 2人 |
| 文明カード | 3枚 |

**2-2-2** 軍事レベル・インフラレベルはそれぞれ0から開始する。

### 2-3 初期カードの準備

**2-3-1** 特別な市民カードは、プレイ人数＋1枚を公開する。

**2-3-2** 自然公園カードは、各プレイヤーに1枚ずつ配る。

**2-3-3** 計画都市カードは、プレイ人数−1枚を公開する。

### 2-4 ボーナスタイル

**2-4-1** ボーナスタイルは10種類用意する。

**2-4-2** 場にはプレイ人数＋3枚を用意する。

**2-4-3** ゲーム開始時、各プレイヤーは初期ボーナスタイルを1枚選択する。選択したタイルはそのプレイヤーが占有し、他プレイヤーは選択できない。

**2-4-3-2** 2-4-3 の選択は、2-6 のドラフトで行う。

**2-4-4** 初期ボーナスタイルの効果は第1ラウンドから適用する。

### 2-5 固有キャラクター

**2-5-1** 各プレイヤーは固有キャラクターを1人選択する。

**2-5-2** キャラクターは5つの評価軸に対応する2種類ずつ、合計10種類を用意する。

**2-5-3** キャラクターには初期資源の変更や固有能力が設定されている。

（整形注）各キャラクターの追加初期資源と固有効果は claude/data_characters.json に定める。

### 2-6 ドラフト

**2-6-1** 個人ボード・ボーナスタイル・固有キャラクターを、同じドラフト候補群に並列して提示する。

**2-6-2** 各種類について、プレイ人数より多い候補を用意する。

**2-6-3** 第1ラウンドの手番順をランダムに決定した後、手番が遅いプレイヤーからドラフトを開始する。

**2-6-4** 各プレイヤーは1回につき1要素を選択する。

**2-6-4-2** 各プレイヤーは、まだ獲得していない種類の要素からのみ選択できる。

**2-6-5** 全員が個人ボード・ボーナスタイル・キャラクターを1つずつ獲得するまで繰り返す。

**2-6-6** 一度選択した要素は変更・交換できない。

**2-6-7** ドラフトは一方向に巡回する。第1ラウンドの手番順の最後のプレイヤーから、手番順と逆の順番で1人ずつ選択する。手番順の最初のプレイヤーが選択した後は、再び最後のプレイヤーから同じ順番で選択する。

### 2-7 初期土地配置

**2-7-1** 通常どおりE1・F1に土地タイルを配置する。

**2-7-2** その後、固有キャラクターなどによる追加の初期土地タイルがあれば、基本ルールに従って配置する。

## 第3章 資源とワーカー

### 3-1 資源

**3-1-1** ゲームで使用する主な資源は以下のとおり。

- 金
- 資材
- 文明カード
- 土地タイル
- 軍事力トークン
- 通常ワーカー
- 臨時ワーカー

**3-1-2** 金・資材・カード・軍事力トークンには保有上限を設けない。

**3-1-3** 臨時ワーカーの保有上限は3人とする。

### 3-2 生産力と収入

**3-2-1** 金・資材の生産力は、ラウンド開始時の収入獲得に使用する。

**3-2-2** 第1ラウンド開始時は、初期生産力に基づいて金20・資材3を獲得する。

**3-2-3** 建物などによる生産力増加は、原則として獲得した次のラウンドから収入に反映する。

**3-2-4** ボーナスタイルによる生産力増加は、獲得したラウンドの収入から反映する。

**3-2-5** 最終ラウンド終了後にも、金・資材の収入を1回だけ獲得する。

### 3-3 通常ワーカー

**3-3-1** 通常ワーカーは初期5人、最大10人。

**3-3-1-2** 通常ワーカーの上限は、5＋住宅数÷2（端数切り捨て）とする。上限は10を超えない。

**3-3-2** 通常ワーカーはラウンド終了時に全員回収し、次のラウンドでも使用する。

**3-3-3** 通常ワーカーを獲得した場合、そのラウンド中は使用できず、次のラウンドから使用できる。

**3-3-4** 通常ワーカーの獲得数が上限を超える場合、超過分は破棄する。

**3-3-5** 通常ワーカーの減少は原則として想定しない。

### 3-4 臨時ワーカー

**3-4-1** 臨時ワーカーは初期2人、最大3人。

**3-4-2** 臨時ワーカーは使用すると失われる。

**3-4-3** 未使用の臨時ワーカーは次のラウンドに持ち越せる。

**3-4-4** 臨時ワーカーを獲得した場合、獲得したラウンド中から使用できる。ただし、獲得したアクションの処理中には使用できず、処理完了後の次の手番から使用できる。

**3-4-4-2** 獲得した臨時ワーカーは、獲得した手番中はフリーアクションを含めて使用できず、自分の次の手番から使用できる。

**3-4-5** 保有上限を超える場合、超過分は破棄する。

**3-4-6** 通常ワーカーと臨時ワーカーは混ぜてアクションに配置できる。

## 第4章 土地の開拓

### 4-1 土地タイル

**4-1-1** 土地タイルは、個人ボードの未開拓マスに配置することで土地を開拓する。

**4-1-2** 土地タイルには地形に対応する種類がある。

**4-1-3** 地形はボード上の元の属性、土地タイルは開拓後の土地の性質を表す。

**4-1-3-2** 土地の種類を参照する効果は、配置された土地タイルの種類を参照する。地形による建設時ボーナス（5-4）、軍事レベル12の報酬（7-1-2）、計画都市カード・自然公園カードの土地種、キャラクター・特別な市民カード・文明カードの効果がこれに当たる。ボード上の地形は、土地タイルの配置条件（4-2）と開拓コスト（4-3）の判定に用いる。

### 4-2 配置条件

**4-2-1** 土地タイルは、既に開拓済みの土地に辺を共有する未開拓マスに配置する。

**4-2-2** 通常の土地タイル獲得では、配置先マスの地形と同じ種類の土地タイルを配置する。

**4-2-3** 異なる種類の土地タイルを配置できるのは、効果に特記がある場合、または開拓アクションを実行する場合に限る。

**4-2-4** 開拓アクションでは、地形と異なる土地タイルを配置する場合、1枚につき追加資材1個を支払う。

**4-2-5** 開拓アクション以外の効果で、異なる土地タイルを配置できると明記されている場合、追加コストは不要。

### 4-3 開拓コスト

**4-3-1** 土地タイル1枚あたりの基本コストは資材2個。

**4-3-2** 地形と異なる土地タイルを配置する場合は、追加資材1個を支払う。

**4-3-3** したがって、1枚あたりの基本コストは以下のとおり。

- 地形一致：資材2個
- 地形不一致：資材3個

**4-3-4** 開拓アクションの上位・最上位では、アクション全体の資材コストをそれぞれ1個・2個軽減する。

**4-3-5** 割引は地形不一致による追加資材にも適用する。金には適用しない。

### 4-4 複数枚の配置

**4-4-1** 土地タイルを複数枚配置する場合、1枚ずつ順番に配置する。

**4-4-1-2** 配置する枚数は配置を始める前に決め、決めた枚数をすべて配置する。途中で配置をやめることはできない。配置先がなくなった分は 4-4-5 に従う。

**4-4-2** 2枚目以降は、それまでに配置した土地タイルのいずれかと辺を共有する未開拓マスを選べる。

**4-4-3** 直前に配置した土地タイルだけと隣接するマスも選択可能。

**4-4-4** すべての土地タイルを配置した後、発生したマスボーナスを任意の順番で処理する。

**4-4-4-2** マスボーナスは、個人ボードの特定のマスに記載されたボーナスであり、そのマスに土地タイルを配置したときに獲得する。マスボーナスを持つマスとその内容は、個人ボードのデータに定める。

**4-4-5** 配置先がない土地タイルは破棄する。土地タイルを手元に保有することはできない。

## 第5章 建物の建設

### 5-1 建設条件

**5-1-1** 建物は、開拓済みで建物が建っていない土地に建設できる。

**5-1-2** 建設先の地形は問わない。

**5-1-3** 建設可能な土地があれば、効果に指定がない限り自由に選択できる。

### 5-2 建物の種類と上限

**5-2-1** 建物の種類と建設上限は以下のとおり。

| 建物 | 建設上限 |
|---|---|
| 商店 | 3 |
| 工房 | 3 |
| 砦 | 3 |
| 役所 | 3 |
| 大学 | 3 |
| 住宅 | 10 |
| 飯場 | 3 |
| 合計 | 28 |

（整形注）原本では本表に導入文がない。本項の1行目は表の見出しとして整形時に付した。

**5-2-2** 各プレイヤーは、建物の種類ごとに上限数と同じ数の建物コマを持つ。

**5-2-3** 建設済みの建物コマは個人ボードに配置し、未建設のコマは手元に残す。

### 5-3 建設コスト

**5-3-1** 建設コストは以下のとおり。

| 建物 | 金 | 資材 |
|---|---|---|
| 住宅 | 2 | 2 |
| その他 | 5 | 3 |

（整形注）本項の1行目は表の見出しとして整形時に付した。

**5-3-2** 建築アクションによる割引や飯場の効果を適用する。

### 5-4 地形による建設時ボーナス

**5-4-1** 地形による建設時ボーナスは以下のとおり。

| 地形 | 対応する建物 | 建設時ボーナス |
|---|---|---|
| 山岳 | 工房・砦 | 資材1個 |
| 水場 | 商店・役所 | 金2個 |
| 平原 | 大学 | 3点 |
| 平原 | 住宅 | 1点 |
| 森林 | なし | 直接の建物ボーナスなし |

（整形注）本項の1行目は表の見出しとして整形時に付した。

**5-4-2** 飯場には地形ボーナスがない。

### 5-5 建物の効果

#### 5-5-1 商店

**5-5-1-1** 建設時、金の生産力＋2。

**5-5-1-2** 輸入アクション後、商店数に応じて金の生産力を増加させる。

- 1軒：＋1
- 2軒：＋2
- 3軒：＋3

**5-5-1-3** 商店2軒で輸入の最上位アクションを解放する。

#### 5-5-2 工房

**5-5-2-1** 建設時、資材の生産力＋1。

**5-5-2-2** 輸出アクション後、工房数に応じて金を獲得する。

- 1軒：2金
- 2軒：4金
- 3軒：6金

**5-5-2-3** 工房2軒で輸出の最上位アクションを解放する。

#### 5-5-3 砦

**5-5-3-1** 建設時、軍事レベル＋1。

**5-5-3-2** 教練による軍事レベル上昇に必要な軍事力トークンを、砦1軒につき1個軽減する。

- 砦0軒：4個
- 砦1軒：3個
- 砦2軒：2個
- 砦3軒：1個

**5-5-3-3** 砦2軒で教練の最上位アクションを解放する。

**5-5-3-4** この軽減は教練にのみ適用し、襲撃・遠征には適用しない。

#### 5-5-4 役所

**5-5-4-1** 建設時、インフラレベル＋1。

**5-5-4-2** 福祉アクション後、臨時ワーカー1人を資材に変換できる。

- 役所1軒：2資材
- 役所2軒：3資材
- 役所3軒：4資材

**5-5-4-3** 役所2軒で福祉の最上位アクションを解放する。

#### 5-5-5 大学

**5-5-5-1** 建設時、文明カード2枚を引く。

**5-5-5-2** 大学1軒につき、文明カードのプレイコストを1金軽減する。最低0金。

**5-5-5-3** 大学2軒で研究の最上位アクションを解放する。

#### 5-5-6 住宅

**5-5-6-1** 建設時の即時効果はない。

**5-5-6-2** 住宅2軒ごとに通常ワーカーの上限を1人増やす。

**5-5-6-3** 住宅5軒で移住の最上位アクションを解放する。

**5-5-6-4** 通常ワーカーの最大数は10人。

#### 5-5-7 飯場

**5-5-7-1** 建設時、土地タイル1枚を獲得し、即時配置する。

**5-5-7-2** 飯場のマスに隣接する周囲6マスへの建物建設コストを資材1個軽減する。盤面の端では、周囲のマスは6マスより少なくなる。

**5-5-7-3** 複数の飯場の範囲が重なっても、飯場による軽減は最大1資材。

**5-5-7-4** 開拓コストは軽減しない。

**5-5-7-5** 地形ボーナスはない。

**5-5-7-6** 建設場所の制限はない。

### 5-6 複数建物の建設処理

**5-6-1** 同時に複数の建物を建設する場合、最初に建設する建物の種類と軒数をすべて選択し、コストを確定する。

**5-6-2** その後、建物をすべて配置する。

**5-6-3** 建設時効果と地形ボーナスは、すべての建設が完了した後に任意の順番で処理する。

**5-6-4** 一連の建設処理中に発生した効果は、同じ処理内の後続建設には影響しない。

**5-6-5** 例えば、1軒目に飯場を建設しても、その飯場の建設時効果やコスト軽減は、同じ処理で建設する2軒目には適用しない。

**5-6-6** 建築アクションの割引と飯場の軽減は重複する。コストは0未満にならない。

**5-6-7** 無料建設の場合、建築コストのみ免除し、建設条件・建物上限・建設時効果・地形ボーナスは通常どおり適用する。

## 第6章 ワーカープレイスメント

### 6-1 アクションの基本ルール

**6-1-1** 通常アクションは1ワーカー、上位アクションは2ワーカー、最上位アクションは3ワーカーを配置して実行する。

**6-1-2** 通常・上位・最上位のアクションスペースはそれぞれ独立している。

**6-1-3** 上位アクションは最初から解放されている。

**6-1-4** 最上位アクションは個別の解放条件を満たすことで使用可能になる。一度解放した最上位アクションはゲーム中維持される。

**6-1-5** 解放条件を満たした場合、そのアクションの処理完了直後から同じラウンド中でも使用できる。

**6-1-6** 「最大N」と記載された効果は、0からNまでの数を選んで実行できる。ただし、アクション全体として何も実行しない選び方はできない。ワーカーを配置するだけのアクションは認めない。

**6-1-6-2** 輸入・輸出で交換を1回も行わない選び方は、何も実行しない選び方に当たり、選択できない。

**6-1-7** アクションのコストは実行内容を選んだ時点で確定する。コストを支払えない組み合わせは選択できない。

### 6-2 アクションスペースの占有

**6-2-1** 占有型のアクションスペースは、使用したプレイヤーを含め、そのラウンド中は再使用できない。

**6-2-2** 通常の開拓・建築・移住・普及は共有スペースとし、同じプレイヤーも同じラウンド中に複数回使用できる。

**6-2-3** アクションスペースの占有はラウンド終了時に解除する。

**6-2-4** 特別な市民カードに記載されたアクションスペースは、そのカードを獲得したプレイヤーだけが使用できる。

**6-2-5** 特別な市民カード09・10・11・14のアクションスペースは占有型とし、1ラウンドに1回だけ使用できる。

### 6-3 アクション一覧

#### 6-3-1 開拓

**6-3-1-1** 開拓の効果は以下のとおり。

| 種類 | 効果 |
|---|---|
| 通常 | 土地タイルを最大2枚配置 |
| 上位 | 最大3枚配置。合計資材コスト−1 |
| 最上位 | 最大5枚配置。合計資材コスト−2 |

**6-3-1-2** 最上位解放条件：建物4軒。

#### 6-3-2 建築

**6-3-2-1** 建築の効果は以下のとおり。

| 種類 | 効果 |
|---|---|
| 通常 | 建物を最大2軒建設 |
| 上位 | 最大3軒建設。合計コスト−1資材・−1金 |
| 最上位 | 最大4軒建設。合計コスト−2資材・−2金 |

**6-3-2-2** 建設する建物の種類は自由に選択できる。ただし個別の建物上限を超えてはならない。

**6-3-2-3** 最上位解放条件：土地タイル7枚。

#### 6-3-3 輸入

**6-3-3-1** 金を支払って資材を獲得する。

**6-3-3-2** 輸入の交換は以下のとおり。

| 種類 | 交換 | 最大回数 | 追加効果 |
|---|---|---|---|
| 通常 | 3金→1資材 | 3回 | なし |
| 上位 | 7金→2資材 | 3回 | 1回以上交換すると2資材 |
| 最上位 | 8金→3資材 | 3回 | 1回以上交換すると3資材 |

**6-3-3-3** 最上位解放条件：商店2軒。

#### 6-3-4 輸出

**6-3-4-1** 資材を支払って金を獲得する。

**6-3-4-2** 輸出の交換は以下のとおり。

| 種類 | 交換 | 最大回数 | 追加効果 |
|---|---|---|---|
| 通常 | 1資材→5金 | 3回 | なし |
| 上位 | 2資材→9金 | 3回 | 1回以上交換すると4金 |
| 最上位 | 3資材→14金 | 3回 | 1回以上交換すると8金 |

**6-3-4-3** 最上位解放条件：工房2軒。

#### 6-3-5 教練

**6-3-5-1** 金を支払い、軍事力トークンを獲得する。獲得したトークンを使用して軍事レベルを上昇させることができる。

**6-3-5-2** 教練の内容は以下のとおり。

| 種類 | 金コスト | 獲得トークン | 上昇処理の上限 |
|---|---|---|---|
| 通常 | 3 | 3 | 1回 |
| 上位 | 6 | 5 | 2回 |
| 最上位 | 9 | 8 | 3回 |

**6-3-5-3** 軍事レベル上昇処理は任意の回数実行できる。

**6-3-5-4** 1回の上昇処理につき、砦の数に応じた軍事力トークンを支払い、軍事レベルを1上昇させる。

**6-3-5-5** 軍事レベルの上限は12。

**6-3-5-6** 軍事レベル12を超える上昇処理を行った場合、軍事レベルは12のままとし、超過上昇処理1回につき2点を獲得する。

**6-3-5-7** 最上位解放条件：砦2軒。

#### 6-3-6 遠征

**6-3-6-1** 軍事レベルに応じた報酬を獲得する。

**6-3-6-2** 遠征の報酬は以下のとおり。

| 軍事レベル | 報酬 |
|---|---|
| 0 | 2金 |
| 1 | 1資材 |
| 4 | 土地タイル1枚 |
| 7 | 建設の権利1回 |
| 10 | 2点 |

**6-3-6-3** 遠征時は、獲得したい報酬のうち最も高い軍事レベルを目標値として宣言する。

**6-3-6-4** 軍事レベルとの差分だけ軍事力トークンを消費する。軍事レベルが目標値以上なら消費不要。

**6-3-6-5** 宣言した目標値以下の報酬をすべて獲得する。

**6-3-6-6** 報酬の選択数は以下のとおり。

| 種類 | 報酬の選択数 |
|---|---|
| 通常 | 異なる報酬を2種類まで |
| 上位 | 異なる報酬を3種類まで |
| 最上位 | 報酬合計5個。同じ報酬は最大2回まで |

**6-3-6-7** 建設の権利では、通常の建設コストを支払って建物を1軒建設できる。

**6-3-6-8** 建設時効果・地形ボーナスは通常どおり適用する。

**6-3-6-9** 遠征で獲得した報酬は任意の順番で処理できる。ただし、実行できない報酬は選択できない。

**6-3-6-10** 最上位解放条件：軍事レベル5。

#### 6-3-7 福祉

**6-3-7-1** 福祉の内容は以下のとおり。

| 種類 | 資材コスト | インフラ上昇 | 臨時ワーカー |
|---|---|---|---|
| 通常 | 2 | 1 | なし |
| 上位 | 5 | 2 | 1人 |
| 最上位 | 8 | 3 | 2人 |

**6-3-7-2** 最上位解放条件：役所2軒。

#### 6-3-8 移住

**6-3-8-1** 通常ワーカーを獲得する。

**6-3-8-2** 移住の効果は以下のとおり。

| 種類 | 効果 |
|---|---|
| 通常 | 通常ワーカー1人 |
| 上位 | 臨時ワーカー1人＋通常ワーカー最大2人 |
| 最上位 | 臨時ワーカー2人＋通常ワーカー最大3人 |

**6-3-8-3** 通常ワーカーは次ラウンドから使用できる。

**6-3-8-4** 最上位解放条件：住宅5軒。

#### 6-3-9 研究

**6-3-9-1** 文明カードを引き、手札を整理する。

**6-3-9-2** 研究の内容は以下のとおり。

| 種類 | ドロー | 捨てる枚数 |
|---|---|---|
| 通常 | 2枚 | 1枚 |
| 上位 | 3枚 | 1枚 |
| 最上位 | 5枚 | 2枚 |

**6-3-9-3** 最上位解放条件：大学2軒。

#### 6-3-10 普及

**6-3-10-1** 文明カードをプレイする。

**6-3-10-2** 普及の内容は以下のとおり。

| 種類 | プレイ可能枚数 | 追加効果 |
|---|---|---|
| 通常 | 1枚 | なし |

**6-3-10-3** カードは1枚ずつプレイし、1枚の処理が完了した後、次のカードをプレイするか選択する。

**6-3-10-4** 最上位解放条件：文明カード4枚プレイ。

## 第7章 軍事・防衛

### 7-1 軍事レベル

**7-1-1** 軍事レベルは初期0、最大12。

**7-1-2** 軍事レベル到達時に以下の報酬を得る。

| 到達レベル | 報酬 |
|---|---|
| 3 | 軍事力トークン2個 |
| 6 | 資材3個 |
| 9 | 土地タイル2枚 |
| 12 | 開拓済み山岳に建物1軒を無料建設 |

**7-1-3** 各報酬はゲーム中1回限り。

**7-1-4** 複数のレベルを一度に上昇した場合、通過したレベルの報酬もすべて獲得する。

**7-1-5** 軍事レベルそのものは得点化しない。ただし、レベル12を超える上昇処理では、1回につき2点を獲得する。

### 7-2 軍事力トークン

**7-2-1** 軍事力トークンは、襲撃・遠征で軍事レベルを一時的に補うために使用する。

**7-2-2** 使用時は目標値を宣言し、目標値と現在の軍事レベルの差分だけトークンを消費する。

**7-2-3** 軍事力トークンによる一時的な軍事力は13以上にもできるが、撃退ラインの最大値は12であるため、それ以上の追加効果はない。

### 7-3 襲撃カード

**7-3-1** 第1ラウンドはカード1を固定で使用する。

**7-3-2** ゲーム開始時にカード2～5をシャッフルし、第2～5ラウンドに順番に使用する。

**7-3-3** 各ラウンド開始時に該当する襲撃カードを公開し、ラウンド終了時に判定する。

### 7-4 防衛ラインと撃退ライン

**7-4-1** 防衛ライン・撃退ラインは初期値0。

**7-4-2** 襲撃カードに記載された増加値をそれぞれ独立して累積する。

**7-4-3** 襲撃時、プレイヤーは防衛ラインまたは撃退ラインのどちらかを目標として宣言する。

**7-4-4** 目標値と軍事レベルの差分だけ軍事力トークンを消費する。

**7-4-5** 判定は以下のとおり。

- 防衛失敗：防衛ライン未達
- 防衛成功：防衛ライン以上、撃退ライン未満
- 撃退成功：撃退ライン以上

### 7-5 襲撃時の得点

**7-5-1** 基本得点効果は以下のとおり。

| 結果 | 基本得点 |
|---|---|
| 防衛失敗 | 襲撃ラウンド数×−1点 |
| 防衛成功 | 0点 |
| 撃退成功 | 襲撃ラウンド数×2点 |

**7-5-2** カード固有の得点効果がある場合は基本得点に加算し、カードに合算後の数値を記載する。

### 7-6 襲撃カードのその他の効果

**7-6-1** 現行のカード固有効果は以下のとおり。

| カード | 防衛失敗時 | 撃退成功時 |
|---|---|---|
| 1 | 次の収入後、3金を失う | 土地タイル1枚を即時配置 |
| 2 | 次の収入後、襲撃ラウンド数×1資材を失う | 襲撃ラウンド数×1資材 |
| 3 | 金の生産力を襲撃ラウンド数分失う | 襲撃ラウンド数分の土地タイルを配置 |
| 4 | 次の収入後、襲撃ラウンド数×2金を失う | 襲撃ラウンド数×1金と同数の点 |
| 5 | 襲撃ラウンド数×−3点 | 襲撃ラウンド数×4点 |

**7-6-2** カード1～4の撃退報酬は基本得点と固有効果を合算したものとする。

**7-6-3** 最終ラウンドにカード1・2・4で防衛失敗した場合、損失は最終追加収入の後に適用する。

## 第9章 カードの共通ルール

### 9-1 文明カード

**9-1-1** 文明カードは山札・手札・捨て札・プレイ済み置き場を区別して管理する。

**9-1-2** 文明カードをプレイした場合、捨て札には置かず、プレイヤーの前にプレイ済みカードとして置く。

**9-1-3** プレイ済みカードは、他の効果から枚数や内容を参照される場合がある。

**9-1-4** 山札が空になった場合、その時点の捨て札をシャッフルして新しい山札にする。

**9-1-5** 山札と捨て札の両方が空の場合、カードを引く代わりに資材1個を獲得する。

**9-1-6** 複数枚ドロー中にカードが不足した場合、引けなかった1枚につき資材1個を獲得する。

**9-1-7** 手札上限は設けない。

### 9-2 文明カードのプレイ

**9-2-1** 文明カードには「プレイ条件」と「効果適用条件」がある。

**9-2-2** プレイ条件を満たさないカードはプレイできない。

**9-2-3** 効果適用条件を満たしていなくてもプレイは可能。ただし該当効果は不発となり、カードはプレイ済みとして残る。

**9-2-4** プレイ手順は以下のとおり。

1. プレイ条件を確認する。
2. カード記載の金コストに大学数による軽減を適用する。
3. 軽減後のコストを支払う。
4. カードをプレイ済み置き場へ移動する。
5. カード効果を処理する。

**9-2-5** 複数枚プレイする場合は1枚ずつ処理する。

**9-2-6** 先にプレイしたカードの効果で得た資源は、後続カードのコストに使用できる。

**9-2-7** 1枚のカードに複数の効果がある場合、各効果の適用条件を個別に判定する。

**9-2-8** カードに処理順の指定がなければ、効果の適用順序はプレイヤーが選択する。

**9-2-9** 文明カードには常時効果を持つものがある。常時効果は、カードがプレイ済み置き場にある間、継続して適用する。

### 9-3 特別な市民カード

**9-3-1** 特別な市民カードはゲーム開始時にプレイ人数＋1枚を公開する。

**9-3-2** 獲得条件を満たしたプレイヤーは公開カードから1枚を選択して獲得し、山札から1枚公開して補充する。

**9-3-2-2** インフラレベルの到達報酬（8-1-2）やキャラクターの効果で特別な市民カードを獲得する場合も、9-3-2 に従い公開カードから1枚を選び、山札から1枚補充する。

**9-3-3** カード効果は獲得した時点から有効。

- 永続効果：獲得直後から適用
- フリーアクション：獲得後の手番から使用可能
- 専用アクションスペース：獲得後の手番から使用可能

**9-3-4** 既に終了した処理に効果を遡及させない。

（整形注）各カードの効果は claude/data_special_citizens.json に定める。原本の一覧シートの表題は「特別な住民カード」である。

## 第10章 フリーアクション

### 10-1 フリーアクション

**10-1-1** フリーアクションは、自分の手番中に通常アクションの前後で実行できる。

**10-1-2** 回数制限のないフリーアクションは、条件を満たす限り何度でも実行できる。

**10-1-3** 現行の資源変換は以下のとおり。

| 支払うもの | 獲得するもの |
|---|---|
| 5金 | 1資材 |
| 15金 | 文明カード1枚 |
| 1資材 | 1金 |
| 軍事力トークン3個 | 1資材 |
| 文明カード1枚 | 1資材 |
| 臨時ワーカー1人 | 1資材 |

**10-1-4** フリーアクションで獲得した資源は、その後のフリーアクションや通常アクションに使用できる。

**10-1-5** アクションの処理途中にはフリーアクションを実行できない。

**10-1-6** パスした後はフリーアクションも実行できない。

## 第11章 ボーナスタイル

### 11-1 構成

**11-1-1** ボーナスタイルは10種類。

**11-1-2** 場にはプレイ人数＋3枚を用意する。

### 11-2 効果

**11-2-1** 各タイルの効果は以下のとおり。

| 番号 | 効果 |
|---|---|
| 1 | 土地タイル1枚獲得／軍事力トークン1個獲得 |
| 2 | 8金獲得 |
| 3 | 資材2個獲得 |
| 4 | 文明カード2枚を引き、手札全体から任意の1枚を捨てる |
| 5 | 臨時ワーカー1人獲得 |
| 6 | 3金獲得／パス時、住宅1軒につき1点 |
| 7 | 資材生産力＋1／パス時、建設済み建物の種類数につき1点 |
| 8 | 金生産力＋2／パス時、プレイ済み文明カード2枚につき1点 |
| 9 | 軍事レベル＋1 |
| 10 | インフラレベル＋1 |

（整形注）本項の1行目は表の見出しとして整形時に付した。

**11-2-2** 「／」で区切られた効果は両方適用する。

**11-2-3** No.7・8の生産力増加は永続し、タイルを返却しても失われない。

**11-2-4** No.7の建物種類数は、同じ種類を複数建設していても1種類として数える。

**11-2-5** No.6～8のパス時得点は、パス宣言時点の状態を参照する。

### 11-3 パス時の交換

**11-3-1** パス時は、パス時効果を処理してから現在のタイルを返却し、次ラウンド用タイルを選択する。

**11-3-2** 返却したタイルはその選択時には選べない。他プレイヤーが占有しているタイルも選択できない。

**11-3-3** 新しいタイルの効果は次ラウンドから適用する。

## 第12章 ラウンドの進行

### 12-0 総則

**12-0-1** 各ラウンドは以下の順序で進行する。

1. ボーナスタイルの効果を獲得する。
2. その他のラウンド開始時効果を処理する。
3. 生産力に応じた金・資材を獲得する。
4. スタートプレイヤーから順番に手番を行う。
5. 全員がパスしたら襲撃を処理する。
6. ワーカーを回収する。
7. 次のラウンドへ進む。

**12-0-2** ラウンド開始時の効果で、金・資材・生産力などの獲得以外の処理がある場合は手番順に行う。

**12-0-2-2** 12-0-2 の手番順は、そのラウンドの手番順とする。

**12-0-3** 第1ラウンドのスタートプレイヤーはランダムに決定する。

**12-0-4** 第1ラウンドは、スタートプレイヤーから時計回りに手番を行う。

**12-0-5** 第2ラウンド以降は、前のラウンドでパスした順番をそのまま手番順とする。

**12-0-6** 各手番では、アクションを1回実行するか、パスを宣言する。アクションを実行せずに手番を終えることはできない。フリーアクションと計画都市カードの達成宣言は、アクションの前後に実行できる。

**12-0-7** 使用できるワーカーがない場合も、パスは自動では行わない。プレイヤーが宣言する。

### 12-1 パス

**12-1-1** プレイヤーは自分の手番にパスを宣言できる。

**12-1-2** パス時効果があれば先に処理し、その後、現在のボーナスタイルを返却して次ラウンド用のタイルを選択する。

**12-1-3** パスしたプレイヤーは、そのラウンド中は以後のアクションを一切実行できない。

**12-1-4** フリーアクションも実行できない。

### 12-2 最終ラウンド

**12-2-1** 第5ラウンド終了時は、襲撃処理とワーカー回収を行った後、最終収入を獲得する。

**12-2-2** その後、最終得点計算を行う。

## 第13章 計画都市カード

### 13-1 公開

**13-1-1** 計画都市カードは共有目標としてゲーム開始時にプレイ人数−1枚を公開する。

**13-1-2** ゲーム中の補充はない。

### 13-2 達成条件

**13-2-1** 各カードには3～5軒の建物の並びが指定されている。

**13-2-2** 条件は以下の3種類を組み合わせて設定する。

1. 土地種・建物種の両方を指定
2. 土地種のみ指定し、建物種は任意
3. 土地種は任意とし、建物種のみ指定

### 13-3 達成宣言と得点

**13-3-1** 指定された建物の配置条件を満たしたプレイヤーは、自分の手番中に達成を宣言できる。

**13-3-2** 宣言はアクション実行前または実行後に行える。

**13-3-3** 達成条件を満たしていても、宣言を見送ることができる。

**13-3-4** 得点は達成宣言の先着順で決定する。

| 順位 | 得点 |
|---|---|
| 1位 | 7点 |
| 2位 | 5点 |
| 3位 | 3点 |
| 4位以下 | 宣言不可 |

**13-3-5** 宣言できる人数はプレイ人数−1人。

**13-3-6** 達成順位はカードごとに独立して管理し、カード上の順位マーカーで記録する。

**13-3-7** 建物は複数の計画都市カードの達成に重複使用できる。

**13-3-8** 達成宣言時にカード記載の恩恵を獲得する。

### 13-4 達成後の扱い

**13-4-1** 達成済みカードは場に残す。

**13-4-2** 達成宣言後は、通常の巻き戻し可能期間を過ぎると達成を取り消せない。建物が移動・撤去されて条件を満たさなくなっても、達成状態・得点・恩恵・順位マーカーは維持する。

---

## 第14章 自然公園カード

### 14-1 配布と条件

**14-1-1** 自然公園カードは各プレイヤーに1枚ずつ配布する個人目標である。

**14-1-2** 1枚のカードには3セットの条件が記載される。

**14-1-3** 各セットは土地種と配置形状を指定する。

**14-1-4** すべてのセットに森林を必ず含む。

### 14-2 得点

**14-2-1** 得点は以下のとおり。

| 達成条件 | 得点 |
|---|---|
| 2枚セット | 5点 |
| 3枚セット | 10点 |
| 4枚セット | 15点 |

**14-2-2** 3セットすべて達成した場合、最大30点。

### 14-3 判定

**14-3-1** 対象となる土地はゲーム終了時に建物が建っていないこと。

**14-3-2** 指定された土地種と形状を満たし、セット内の土地タイルはすべて辺を共有して隣接していなければならない。

**14-3-3** 指定形状と点対称の配置も認める。向きは問わない。

**14-3-4** 同じ土地タイルを複数セットで共有することはできない。

**14-3-5** 3セット同士は隣接している必要はない。

**14-3-6** 達成判定はゲーム終了時に行う。

## 第15章 巻き戻し

### 15-1 巻き戻し

**15-1-1** プレイヤーのアクションが完了するまでは、原則として巻き戻しを認める。

**15-1-2** ただし、以下の場合は巻き戻しできない。

- 山札から新たなカードが公開された。
- 次のプレイヤーがアクションを選択した。
- その他の後続ゲーム処理が開始・進行した。

**15-1-3** 巻き戻す場合は、そのアクションで発生した資源・カード・ボーナスなどの変化もすべて元に戻す。

**15-1-4** 計画都市カードの達成宣言と恩恵処理も通常の巻き戻しルールに従う。

## 第16章 同時発生効果と資源不足

### 16-1 同時発生効果

**16-1-1** 同時に発生した複数の効果は、その効果を受けるプレイヤーが任意の順番で処理できる。

**16-1-2** カードやルールに処理順が明記されている場合は、そちらを優先する。

**16-1-3** 効果の処理中に新たな効果が発生した場合は、その発生条件に従って処理する。

**16-1-4** 「〜した時」「〜する度に」と記載された効果は、対象の1単位（1人・1枚・1軒など）ごとに発動する。

**16-1-5** 上限を超えて破棄した通常ワーカー（3-3-4）は、「通常ワーカーを獲得した」に数えない。

### 16-2 資源不足

**16-2-1** 必要な資源が不足しているアクションは選択できない。

**16-2-2** ボーナスなどで実行不能なアクションが発生した場合、そのアクションは破棄し、それ以外の効果・処理は続行する。

**16-2-3** 資源不足によってプレイヤーが脱落することはない。実行可能な別アクションを選択するか、パスする。

**16-2-4** 選択肢のある効果では、実行できない選択肢は選択できない。

**16-2-5** 選択肢のない効果が実行できない場合、その効果は不発とし、残りの効果・処理は続行する。文明カードは、効果が実行できない場合もプレイでき、プレイ済みのカードとして数える。

**16-2-6** 軍事レベル（7-1-2）・インフラレベル（8-1-2）の到達報酬が獲得時に実行できない場合、その報酬は失われる。後から実行できるようになっても獲得しない。

## 第17章 ゲーム終了時の得点計算

### 17-0 総則

**17-0-1** ゲーム終了時は以下の順番で処理する。

1. 最終襲撃処理
2. 最終収入の獲得
3. 最終襲撃失敗による次の収入後の損失処理
4. ゲーム終了時判定のカード・目標の処理
5. 基礎得点と5評価軸の得点計算
6. 合計得点の比較
7. 同点判定

**17-0-2** ゲーム中に獲得した得点のうち、本章で評価軸を指定していないものは「その他」として集計し、合計得点に含める。

**17-0-3** ゲーム中に獲得した得点は、評価軸によらず1本の得点トラックで記録する。評価軸の区分は、終了時に得点の内訳を示すためにのみ用いる。

### 17-1 基礎得点

**17-1-1** 基礎得点は土地・建物・人口の規模を評価する。

**17-1-2** 人口は通常ワーカー数で表す。

**17-1-3** 基礎得点は以下の計算式で求める。

基礎得点 ＝ 土地タイル数÷2（端数切り捨て）＋ 建物数÷2（端数切り捨て）＋ 通常ワーカー数÷2（端数切り捨て）

**17-1-4** 各項目の端数は個別に切り捨てる。

### 17-2 経済・産業

**17-2-1** 最終収入を獲得した後、残った金・資材を得点化する。

**17-2-2** 金の換算率は商店数に応じて変化する。

| 商店数 | 換算率 |
|---|---|
| 0 | 20金につき1点 |
| 1 | 10金につき1点 |
| 2 | 5金につき1点 |
| 3 | 3金につき1点 |

**17-2-3** 資材の換算率は工房数に応じて変化する。

| 工房数 | 換算率 |
|---|---|
| 0 | 10資材につき1点 |
| 1 | 5資材につき1点 |
| 2 | 3資材につき1点 |
| 3 | 2資材につき1点 |

**17-2-4** 端数は切り捨てる。

### 17-3 文化・学術

**17-3-1** プレイ済み文明カードの固有得点に加え、プレイ枚数に応じた追加得点を獲得する。

| 大学数 | 追加得点 |
|---|---|
| 0 | 5枚につき1点 |
| 1 | 4枚につき1点 |
| 2 | 3枚につき1点 |
| 3 | 2枚につき1点 |

**17-3-2** 端数は切り捨てる。

### 17-4 生活・福祉

**17-4-1** 通常ワーカー数と役所数に応じて追加得点を獲得する。

| 役所数 | 追加得点 |
|---|---|
| 0 | なし |
| 1 | 通常ワーカー数÷3 |
| 2 | 通常ワーカー数÷2 |
| 3 | 通常ワーカー数 |

**17-4-2** 端数は切り捨てる。

**17-4-3** 特別な市民カードの得点効果があれば追加する。

### 17-5 自然・環境

**17-5-1** 自然公園カードと計画都市カードの得点を合計する。

**17-5-2** 特別な市民カードなどに追加効果がある場合は適用する。

### 17-6 軍事・防衛

**17-6-1** 軍事レベル自体は得点化しない。

**17-6-2** 襲撃や遠征、その他の軍事関連効果によって獲得した得点を合計する。

**17-6-2-2** 教練の超過上昇処理による得点（6-3-5-6）と、英雄の撃退成功時の得点は、17-6-2 の軍事関連効果に含める。

### 17-7 勝敗判定

**17-7-1** 全得点を合計し、最も高いプレイヤーが勝者となる。

**17-7-2** 同点の場合は以下の順番で比較する。

1. 経済・産業の金換算後、得点に換算されずに残った金が多いプレイヤー
2. 基礎得点が高いプレイヤー
3. それでも同じ場合は引き分け

**18-1-2** 以下の項目は、実際のプレイ結果をもとに調整する。

- 各評価軸の得点バランス

## 第19章 暫定規定

### 19-0 総則

**19-0-1** 本章は、未決点のうちユーザーの委任により暫定的に定めた規定である（decisions.md 4-7）。実装とテストプレイは本章に従い、異論があれば変更する。

**19-0-2** 本章の規定と他の章の規定が矛盾する場合は、本章を優先する。各項の末尾の〔 〕は decisions.md の項目番号である。

### 19-1 土地と建設

**19-1-1** 土地タイルの資材コスト（4-3）は、開拓アクションで配置する場合にのみ支払う。開拓アクション以外の効果で土地タイルを獲得・配置する場合、資材は支払わない。配置条件は 4-2 に従う。〔2-22〕

**19-1-2** 開拓アクションの割引後の資材コストは0未満にならない。〔2-39〕

**19-1-3** 建設の権利（6-3-6-7）による建設では、建築アクションの割引は適用しない。飯場の軽減と、キャラクター・特別な市民カードによる軽減は適用する。〔2-6〕

**19-1-4** 複数の建物を建設する場合、建設できる土地の数を超える軒数は選択できない。〔3-3〕

**19-1-5** 自然公園カードの形状は、回転した配置を認め、鏡像の配置は認めない。精霊チップが置かれた土地も判定の対象になる。〔2-3〕

**19-1-6** 計画都市カードの条件は、カードに描かれた形状と一致する建物の組が個人ボード上に存在すれば満たす。回転した配置を認め、鏡像の配置は認めない。〔2-4〕

### 19-2 アクション

**19-2-1** 輸入・輸出は、交換回数を先に決めて実行する。追加効果の「1回以上交換すると」は、決めた回数で判定する。〔3-5〕

**19-2-2** 商店・工房の効果（5-5-1-2、5-5-2-2）は、輸入・輸出を実行するたびに発動する。特別な市民カード11で輸入・輸出の効果を使用した場合も発動する。〔2-12〕

**19-2-3** 教練の「上昇処理の上限」は、1回の教練で実行できる上昇処理の最大回数である。0回から上限回数までを選べる。使わなかった軍事力トークンは保持する。〔2-9〕

**19-2-4** 遠征では目標値を宣言し、目標値以下の報酬の中から 6-3-6-6 の選択数まで選んで獲得する。〔2-24〕

**19-2-5** 遠征の最上位で建設の権利を2回選んだ場合、1軒ずつ別々に建設し、それぞれ通常の建設コストを支払う。報酬を実行できるかは選択時点の状態で判定し、同じ遠征で得る他の報酬は含めない。〔2-10〕

**19-2-6** 指揮官の遠征報酬の追加（レベル6・9）は、指揮官の遠征報酬表に新しい報酬として加わる。選択数の数え方は他の報酬と同じである。〔1-8〕

**19-2-7** 役所の変換（5-5-4-2）は、福祉1回につき臨時ワーカー1人までとする。〔2-11〕

**19-2-8** 研究で捨てるカードは、引いたカードを含む手札全体から選ぶ。〔3-6〕

**19-2-9** インフラレベル12を超える上昇は破棄し、得点などには変換しない。〔2-31〕

**19-2-10** 最上位アクションの解放条件では、初期配置の土地タイル（E1・F1）と初期配置で建てた建物も数える。芸術家と特別な市民カード10による無料プレイも、文明カードのプレイに数える。〔2-7〕

**19-2-11** 特別な市民カード11で他のアクションスペースの効果を使用する場合、そのスペースのワーカー数は支払わず、そのスペースを占有しない。最上位アクションの効果を使用した場合は、特別な市民カード02の「最上位アクションを実行する度」に数える。〔3-7〕

### 19-3 襲撃

**19-3-1** 「襲撃ラウンド数」は、その襲撃を判定するラウンドの番号（1〜5）である。〔2-8〕

**19-3-2** 襲撃時に宣言できる目標は、不足分の軍事力トークンを支払えるものに限る。プレイヤーは宣言しないことも選べる。宣言しない場合はトークンを使わず、軍事レベルだけで判定する。〔2-8〕

**19-3-3** 襲撃カード1〜4では、7-5-1 の基本得点に加えて 7-6-1 の固有効果を適用する。例えばカード4の撃退成功では、基本得点（襲撃ラウンド数×2点）に加えて、襲撃ラウンド数×1金と同数の点を得る。カード5の得点は基本得点を含めた合算後の数値であり、基本得点は加えない。〔2-26〕

**19-3-4** 襲撃カードの「〜を失う」で保有量が足りない場合は、保有量を0にして終える。金の生産力は0未満にならない。〔2-27〕

### 19-4 ラウンドとカード

**19-4-1** ボーナスタイル以外による生産力の増加は、獲得した次のラウンドの収入から反映する。ゲーム開始前の準備で増加した生産力は、第1ラウンドの収入から反映する。〔曖昧語 3-2-3〕

**19-4-2** 第5ラウンドのパスでは、パス時効果を処理し、ボーナスタイルの返却と選択は行わない。〔3-13〕

**19-4-3** 特別な市民カードの山札が空のときは補充しない。公開カードが0枚のときに特別な市民カードを獲得する場合、その獲得は不発とする。〔3-12〕

**19-4-4** 「特別な住民カード」と「特別な市民カード」は同一物とする。山札は、公開カードを除いた残りをシャッフルして作る。〔1-7〕

**19-4-5** 場に出すボーナスタイルは、10種からランダムにプレイ人数＋3枚を選ぶ。〔1-6〕

**19-4-6** 軍事力トークンはラウンドをまたいで保持でき、上限はない。〔2-20〕

**19-4-7** 計画都市カードの達成宣言は、手番中の選択肢として1枚ずつ行う。〔3-9〕

**19-4-8** 自然公園カードの得点は、ゲーム終了時に得点が最大となるセットの割り当てで計算する。〔3-8〕

### 19-5 キャラクター

**19-5-1** 英雄は、E1・F1 のうち1枚（プレイヤーが選ぶ）の代わりに、個人ボードの任意の山岳マスに山岳の土地タイルを置き、そこに砦1軒を無料で建設する。砦の建設時効果と地形ボーナスは 5-6-7 に従って適用する。〔2-32〕

**19-5-2** デザイナーの追加初期資源の土地タイル2枚は、E1・F1 の配置の後に 4-2 に従って配置する。資材は支払わない。〔2-33〕

**19-5-3** デザイナーの専用計画都市カードは、計画都市カードの山札から引く。他のプレイヤーにも公開し、デザイナーだけが達成を宣言できる。得点は7点とする。〔1-3、2-38〕

**19-5-4** 指揮官・官僚の「建設時に〜が1上昇する」は、建物本来の上昇（5-5-3-1、5-5-4-1）に加えて上昇する。〔2-35〕

**19-5-5** 資本家のゲーム終了時の資材獲得は、17-0-1 の手順4で行う。〔2-37〕

**19-5-6** 芸術家の最初の手番開始時の無料プレイは必ず行う。プレイ条件は適用する。プレイできるカードがない場合は行わない。〔3-14〕

**19-5-7** 精霊使いの精霊チップは、土地種ごとに1個、計4個とする。フリーアクションで、使用していない精霊チップ1個と、その種類の土地タイル1枚を、同じ地形のマスに 4-2-1 に従って置く。資材は支払わない。置いた精霊チップは3ラウンド目の襲撃の後に回収するまで再使用できない。精霊チップのある土地は、自然公園・計画都市の判定では通常の土地として扱う。〔1-8、3-10〕

### 19-6 情報と運用

**19-6-1** 非公開情報は、文明カードの手札の内容と山札の順序のみとする。手札の枚数と自然公園カードは公開する。〔4-2、4-4〕

**19-6-2** 土地タイル・軍事力トークン・臨時ワーカーのストックは無限とする。〔4-6〕

**19-6-3** 15-1-2 に加え、襲撃の判定、ドラフトの選択、ボーナスタイルの選択も巻き戻せない処理とする。〔4-1〕

**19-6-4** データの文言の表記揺れは、「特別な市民カード」「軍事レベル」「軍事力トークン」「生産力」「人」と読み替える。〔表記・用語〕
