## 4-0. 目的と範囲

- 効果・コスト・報酬・条件を、文章ではなくアイコンと数字の並びで読めるようにする（ui_design.md 0-1）。
- 本節は「並べ方の約束（文法）」と「要素の図案の方針」を定める。最終的な絵柄（世界観に合わせた描き込み）は theme.md の後に差し替える。差し替えても文法は変えない。
- 0-1 が区別を求める5点（支払いと獲得、1回と繰り返し、条件付きと無条件、収入と即時、「任意」）を、それぞれ1つの記法で表す（4-3）。

## 4-1. 基本の単位

- 1つのアイコンは「要素（名詞）＋数字」である。数字は要素の右下に小さな札で付ける。数字が1の獲得は省略しない（数え間違いを防ぐ）。
- 大きさは 24px を基準とし、線の太さは 2px、角は丸める。小（カード上）は 18px、大（盤面・パネル）は 32px とし、縮小しても線の太さは 1.5px を下回らない。
- 色だけで区別しない。形で区別し、色は補助とする（色覚の多様性への配慮）。

## 4-3. 文法（並べ方の約束）

### 4-3-1. 支払いと獲得

- 支払いは左、獲得は右に置き、間に右向きの矢（→）を置く。矢の左はすべて支払い、右はすべて獲得である。
- 矢がない並びは、すべて獲得である。
- 支払うアイコンの数字には − を付けない（矢の左にあることで支払いと分かる）。割引・軽減だけは「−1」と書き、コストのアイコンに重ねる。

例：金3 → 資材1（輸入の通常）

### 4-3-2. 1回と繰り返し

- 何も付けない並びは、その場で1回だけ処理する。
- 「〜につき」は斜線（／）で表す。斜線の左が数える対象、右が1単位あたりの獲得である。例：通常ワーカー1 ／ 金1（019）。
- 「〜する度に」（常時効果、16-1-4）は、きっかけの要素を輪の矢（⟳）で囲み、コロンで獲得につなぐ。例：⟳森林 ： 得点2（特別市民01）。
- 回数の制限は右上の札で表す。1ラウンドに1回＝「1R」、ゲーム中1回＝「1」、N回ごと＝「×N」。

### 4-3-3. 条件付きと無条件

- 条件は灰色の丸い枠（カプセル）に入れ、コロン（：）で効果につなぐ。枠の中は「要素 比較 数」の順で、比較は ≥ と < だけを使う。
- 枠がない効果は無条件である。
- 段階のある条件（027〜042）は、条件と効果の組を縦に重ねる。

例：（軍事レベル ≥3）：資材3 ／（軍事レベル ≥6）：資材2

### 4-3-4. 収入と即時

- 生産力（ラウンド開始時の収入、3-2-1）は、資源のアイコンを「台座」（下辺の太い四角）に載せる。台座のない資源は即時の獲得である。
- 例：台座の上の金5＝金の生産力+5（005）、台座なしの金5＝金を5得る。

### 4-3-5. 「任意」と「最大」

- 「最大N」「〜まで」（6-1-6）は、数字の前に ≤ を付ける。例：建物 ≤3（003）。
- プレイヤーが種類を選べるもの（任意の土地タイル、任意の建物）は、4色に分けた図案か、種類の部分を「？」にした図案で表す。
- 「いずれか1つを選ぶ」（学者）は、選択肢の並びを縦線（｜）で区切り、全体を角括弧で囲む。

### 4-3-6. いつ処理するか（能力の札）

並びの左端に、処理する時を表す札を置く（効果スクリプトの能力に対応する）。

| 札 | 意味 | 図案 |
|---|---|---|
| プレイ時 | 文明カードをプレイしたとき | カードと星 |
| 獲得時 | 特別な市民カードを獲得したとき | カードと下向きの矢 |
| 準備時 | 追加初期資源 | 旗の0（最初の手番の旗1と対、ユーザー決定 2026-11-03） |
| 最初の手番 | 最初の手番の開始時 | 旗の1 |
| 常時 | 継続する効果・補正 | 輪の矢（⟳） |
| フリーアクション | 手番中にいつでも | 稲妻 |
| 専用スペース | ワーカーを置いて使う | ワーカーの形のくぼみと人数 |
| 終了時 | ゲーム終了時 | 終わりの旗（チェッカー） |

## 4-4. 数字の書き方

- 数字は算用数字の太字とし、札の地は白、縁は要素の色とする。
- 支払い・獲得の区別は位置（4-3-1）で表し、数字の色では表さない。
- 襲撃ラウンド数を掛ける値（7-6-1）は、数字の代わりに「R×2」のように書く。

## 4-5. 色

- 評価軸の5色を基本とする：経済・産業＝黄、文化・学術＝紫、生活・福祉＝橙、自然・環境＝緑、軍事・防衛＝赤。その他は灰。
- 建物は対応する評価軸の色で塗る（商店・工房＝黄、大学＝紫、役所・住宅＝橙、砦＝赤、飯場＝灰）。
- 地形の色は rules.md 2-1-6 に従う。プレイヤー色は評価軸の色と重ならない4色（案：青・桃・水色・黒）とする（ui_design.md 7-3 の委任事項の案）。

## 4-6. 本案で決めないこと

- 共有スペースと占有型スペースの枠、強調の色（ui_design.md 7-3）は5節以降で定める。本案では仮に、共有スペースを破線の枠、占有型を実線の枠とする。
- 絵柄の描き込み、名称（theme.md）。

## 4-7. 実装との対応

- 図案は `src/ui/icon-art.ts` に、`icon_keys.json` の識別子ごとの SVG として持つ。`src/ui/Icon.tsx` はこの表を引き、表にない識別子は従来の仮の素材（色と1字）で出す。
- 4-3 の記法（矢・斜線・輪の矢・カプセル・台座・≤・角括弧）は、`iconSequence` が返す並びを `Icon.tsx` が描くときに付ける。並びの組み立て（`src/game/icons.ts`）は、記法に必要な区切り（支払いと獲得の境目、条件の範囲）を返すよう拡張する。
