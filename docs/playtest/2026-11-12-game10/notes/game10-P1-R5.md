# P1 ノート（指揮官クロユリ・個人ボード4）
## 計画（R5・最終）
1. 開始時にボーナスタイル1の土地タイルを置く（選択待ちのまま。平原に置けば住宅・大学で点）。
2. 遠征3段（最上位→上位→通常）。軍事Lv11なのでLv10の2点はトークン0で取れる。最上位：2点×2＋臨時×2、上位：2点＋臨時＋建設の権利かカード、通常：2点＋臨時。代わり：取られたら残り段。
3. 残りワーカーで普及・通常（共有）。手札：鉱床・名誉ある犠牲・注文住宅・兵法・工学・丘陵・土塁。安い順に打つ（土塁4・兵法3・注文住宅2〜）。
4. 最後に使い切り：手札→資材1、資材4→臨時1、余り金5→資材。建築で住宅（空き地があれば）。
## 方針
- 教練・通常（金3→トークン3、Lv+1にトークン1）が安くて効いた。R4でLv10化→遠征の2点がタダに。
- 式典の警護（Lv+1・Lv分の点）で11点。
- ドロー効果（知識の泉・フラウス）で手札が増えた。
## R4 終了：得点56、金16 資材4、トークン2、Lv11、ボーナスタイル1
## ルールの穴・気づき
- 遠征の点はレベル差のトークンを1遠征に1回払う（報酬ごとではない）。
- 教練の上昇は砦3軒でトークン1。
- move に temp:0/1 を先頭に入れると1回で済む（臨時がいるとき）。
- パスは他の席が手番中だと拒否される。wait してから。
