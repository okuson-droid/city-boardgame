# P2 ノート（R4 終了時。見込み P0 159・P2 137・P1 下位）
## 計画（R5・最終）
1. 住宅10軒（sc05で+4、sc12・住宅街・タイル6パス時で1軒3点）：いま6軒。sc14(W1)で2枚＋開拓・通常で2枚→種類4→専用スペース(W2)で無料2軒、建築・通常で2軒（建物のない土地が要る。土地を先に置く）。
2. インフラ12超過は1段2点：福祉・最上位（資材6で+3＝6点）が第1、取られたら福祉・通常/上位。
3. 移住で通常ワーカー（役所3軒＝1人2点、住宅で上限が上がる）。
4. 使い切り：余った金→資材→福祉、手札→資材1、資材4→臨時1。
## 方針
- 商店・工房・役所・大学は3軒で上限。建てられるのは住宅・砦・飯場だけ。
- 襲撃は雲隠れで raid:skip。ボーナスタイル6を持っている（パス時 住宅1点）。
## ルールの穴・注意
- 建物のない土地がないと建築は選べない（「実行できる内容がない」）。
- 手番中に資材4→臨時1で得た臨時はその手番に使えない。
- 普及の表示コストは大学の軽減後らしい（住宅街 金5のまま払った）。
