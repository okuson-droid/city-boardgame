# P1 知見（指揮官クロユリ・個人ボード4）
## 最終得点 130（3位。P0 242・P2 194）
基礎27（土地9・建物12・ワーカー6）経済8 文化24 生活3 自然3 軍事34 その他31。遠征の報酬だけで34点。
## 効いたもの
1. 砦3＋教練で軍事Lv10以上にし、R3〜R5に遠征3段を毎ラウンド独占（1ラウンド約8点＋臨時4人）。最上位は 2点×2＋臨時×2。
2. R5 建築・最上位で商店・工房・役所を各1軒（+13：商店1軒で金の収入34が経済6点）。持っていない種類の1軒目は終了時の点が大きい。
3. 最後の襲撃の撃退で置く土地タイルを、建物のない種類が4つ揃うように隣接させると自然公園+3（隣り合わないと0）。
## 誤った判断
1. 役所・住宅・移住を後回しにし、通常ワーカー6・インフラ1のまま終わった（生活・福祉3点。P0は89点）。
2. 特別な市民カードを1枚も取らなかった。軍事Lvが高いのに19（Lv+3）も他席に取られた。
3. 商店・工房をR5まで建てず、生産力の上乗せと終了時の点を取り逃した。
## 新しい発見
- 兵法（捨てた枚数だけLv）は2〜3枚捨ててもLv+1しか上がらず得点0だった（上限か仕様か不明）。
- 建築の途中で飯場を建てても、その土地タイルは同じアクションでは使えない（確定後に置く）。
- 文明カードは1枚でも文化・学術が+1〜2（大学3軒）。最終盤は家1軒(+1)よりカード1枚(+2)。
## 分かりにくいルール
- 建築は空き土地が尽きると自動で確定し、続けて done を書くと失敗する。
- 捨てる段の選択肢 ID が card:*（discard:* ではない）。
## コマンドへの要望
- move の失敗時に、いまの選択肢 ID を1行で出してほしい。plan は使ったが「狙い：」の通知は一度も出なかった。
