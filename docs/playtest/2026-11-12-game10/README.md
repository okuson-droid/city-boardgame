# AI 同士の対局と効率化の方法の提出（2026-11-12、ゲーム10）

ユーザー決定（2026-11-12）：新しい機能の効果は分けて測らない。以降は AI 同士の対局を回し、各打ち手に効率化の方法を出させる。手順は `docs/playtest/README.md` の 6-2。

| ファイル | 内容 |
|---|---|
| `replays/game10.json` | 記録（データの版 26b2a3e9） |
| `insights/game10-PN.md` | 各席の最後の打ち手が書いた知見 |
| `notes/game10-PN-R5.md` | 第5ラウンドの打ち手が引き継いだノート |
| `proposals/game10-PN-RM.md` | 各打ち手（5ラウンド×3席の15人）が出した効率化の方法 |
| `proposals.md` | 15人の案を、席とラウンドをまたいでまとめたもの |

## 条件

- シード 20261121、3人。キャラクターは観察の少ない3人を指定した：P0 芸術家（Fable 5.2）、P1 指揮官（Opus 5.5）、P2 デザイナー（Opus 5.5）。
- 運用はゲーム9と同じ（ラウンドごとに作り直し）。打ち手には、ラウンドの終わりに `.play/proposals/P<席>-R<ラウンド>.md`（1KB 以内）を書かせ、前のラウンドの案は読ませなかった。

- 芸術家は第1ラウンドに特別市民03、第3ラウンドに02 を取り、最上位アクションとカードのプレイ（1枚につき金2・1点）を重ねた。調整後の芸術家の初めての観察である。
- 指揮官は毎ラウンド遠征の3段を回し軍事34点を取ったが、生活・福祉が3点（役所・インフラが伸びなかった）。
- デザイナーは調整で加わった専用スペース（無料2軒）を使い、計画都市 PC02・PC06 を1番目に達成した。

## 運用上の観察

- ラウンドの最初の選択（ボーナスタイル1 の土地タイル、インフラの到達報酬の特別市民）が、前のラウンドの打ち手が終えた後に残る例が3回あった（ゲーム9 を合わせて4回）。`wait --round R` はラウンドが替わった時点で終えるため、ラウンド開始の自動処理が積んだ選択は次の打ち手が打つ。対局は止まらない。
- 指示書で禁じた自作の絞り込み（`| head`・`| tail`・`| grep`・`| sed`）が全席で残った。15人中の多くが、案の「自分で変えること」に「wait は先頭だけ読む」「head で読む」を挙げており、既定の出力が長いことへの回避策として使われている。
