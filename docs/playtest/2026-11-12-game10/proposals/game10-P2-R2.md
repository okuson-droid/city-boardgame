# P2 R2 効率化案
## (1) 無駄だった場面
- wait のたびに局面全体（アクション一覧・選べない理由・他席）が出て、同じ内容を5回読んだ。
- 計画都市の座標合わせ（回転）を自分で盤面から計算した。思考量が大きかった。
- 開拓で枚数→マスと段が分かれ、1手を2〜3回の move に分けた（枚数を先に知らずにまとめられない）。
## (2) 変更案
1. wait の出力は前回から変わった欄だけ（出来事＋選択肢）にし、選べないアクションは「使用済み」以外を省く。
2. 計画都市ごとに「あと何マスで達成：置くタイル・建てる建物とマス」を show --only plans で出す。
3. move で count を省き、tile 指定の数から枚数を決められるようにする。
## (3) 自分のやり方
- 盤面は1回だけ見て、座標と残り種類をノートに書く。
- move に count:N とタイル指定を最初からまとめる。
