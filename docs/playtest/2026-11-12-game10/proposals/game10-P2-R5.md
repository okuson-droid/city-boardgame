# P2 R5 効率化
## 無駄だった場面
- 移住・最上位の下見で選択肢の番号を3回試した（「ワーカーの内訳」「獲得人数」の段が下見に出ない）。
- 土地の置き先の ID 形式が分からず C6 を直接指定して失敗、実際に適用してから選択肢を見た。
- 待つたびに show 全体（約200行）が出た。--only を付け忘れた初回の wait が最大の読む量。
## 変更案
1. move --dry-run：止まった段の選択肢（ID と短いラベル）を最大10行出す。
2. wait：既定を --only progress,options 相当にし、局面全体は show で取る。
3. 指示書：最終ラウンドは「資材4→臨時を前の手番で作る」「共有スペースは何度でも」「show --only board でマスボーナスを確認」を計画の項目に入れる。
## 次から
- 最終ラウンドの最初に board を1回見てマスボーナスを計画に入れ、wait は常に --only を付ける。
