# P0 R1 効率化
## 無駄
- wait が毎回局面全文を出す。ドラフト3回で候補一覧を3回読んだ。
- end を忘れ wait が即返り全文を再読。
- 手順の書式が分からず1段ずつ move（4回余計）。
## 変更案
1. wait の既定を出来事＋自分1行＋選択肢だけにする。全文は --state。
2. 残りが end とフリーアクションだけなら move が自動で手番を終える。
3. 指示書に書式例を載せる（`act:pioneer:normal count:2 tile:D1:plains end`、土地1枚=資材2）。
## 自分
- 出力は head/tail で絞る。1手番1 move。計画は最初に1回。
