# P1 R5 効率化
## 無駄だった場面
- 飯場→残り建設を試して undo（飯場のタイルは確定後に置くと知らず）。
- 兵法の捨てる段で discard:* と推測して失敗、done も自動確定で失敗。下見を計3回やり直し。
- --only options で wait したため出来事が欠け、再度 events を取った。
## 変更案
1. dry-run が「選択肢にない指定」で止まったら、その段の選択肢 ID を一覧で出す（推測の再試行をなくす）。
2. 建築の選択肢に「飯場の土地タイルは確定後に置く（この建築では使えない）」を注意として出す。
3. 兵法など効果の上限を、プレイ前の下見に「上がる量 最大N」として出す。
## 自分で変えること
- 最終ラウンドの最初に、手札全部と建てられる建物を1回の --or（4案）で比べ、順番を決めてから打つ。
- wait は --only events,options を既定にする。
