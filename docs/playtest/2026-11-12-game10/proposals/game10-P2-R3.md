# P2 R3 効率化の案
## 無駄
- resume の全文（キャラ8人分・建物表など約15KB）を読んだ。要るのは局面・自分・手札・選択肢。
- 普及・最上位で公共事業の3軒の後に done を付け、普及を終えて2枚分を失った。
- dry-run が「残る選択待ち」の名前しか出さず、本番で1段ずつ進めた。
## 変更案
1. resume --brief：局面・自分・手札・選択肢・見込みだけ。
2. 自動確定した段の直後の done は拒否し「done は普及を終える」と注意する。
3. dry-run の末尾に残る段の選択肢一覧を出す。
## 自分で
- 段の境目で done を付けない。wait は head で読む。
