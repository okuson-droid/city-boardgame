# P1 R2 効率化案
## (1) 無駄
- 建築・最上位の4軒目を同じ move に入れて資材不足で失敗、やり直した。
- 教練の払う量・上昇回数の ID が分からず、アクション単独で move して選択肢を見た。
- wait の全文の表（ボード・建物）は R2 に要らなかった。
## (2) 変更案
1. dry-run の「残る選択待ち」に、その段の選択肢 ID を1行で添える。
2. 建築の選択肢に建物ごとの「払える残り軒数」を出す。
3. resume に `--brief`（局面・自分・他席・選択肢のみ）。
## (3) 自分
- 遠征の報酬 ID（reward:4/6）は固定と分かったので、アクションから報酬・end まで1回の move にする。
- wait の出力は出来事と選択肢だけ見る。
