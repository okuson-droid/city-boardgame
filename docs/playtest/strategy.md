# 戦略の原則（ワーカープレイスメント・拡大再生産の定石から）

手は「1手で何点か」×「残りのラウンドで何回効くか」で比べる。早い手ほど価値が高い。到達報酬・費用・上限は必ず `ref` で確かめてから計画に入れる（思い込みで外した例が多い）。

## 型
- 第1〜2ラウンドは作る（増員・生産・建物の種類・インフラ）。第3ラウンドは作ると点の両立。第4〜5ラウンドは点に替える。
- ワーカー・生産力は行動数と終了時の得点の両方に効く。増員と生産への投資は前倒しする。
- 商店・工房は軒数で終了時の割る数が変わる（金の生産力÷20・5・4・3、資材の生産力÷10・3・2・1）。1軒目が最も効く。第4ラウンドまでに0軒のままにしない。3軒目は最終ラウンドでも1軒5〜11点になる。
- 終盤は1手あたりの基準点を3点以上とし、下回る手を打たない（最終ラウンドは1手3〜16点になる）。

## 取り合い
- 皆が欲しい占有スペースが先、自分しか欲しくない手と共有スペースは後。解放済みの強い最上位は原則1手目。
- 置く前に、相手ごとに「次に欲しいもの」を1行で推定する（空き土地・住宅の数・インフラまでの残り・金）。
- 妨害だけの手は打たない。自分にも良い手でついでに妨害する。
- パスは「残りの手の点」と「次ラウンドの手番＋ボーナスタイル」の比較で決める。

## 得点源
- キャラクターの得意軸を主軸にし、誰にでも効く大きい得点源（特別な市民カード・役所×ワーカー・インフラの点）は捨てない。
- インフラの特別な市民カードは Lv5・10・15、点は Lv1・6・11。それ以外の段は点にならない。1段ずつ `ref` で確かめる。
- 自然公園と計画都市は、土地や建物を置く時点でマスを決める。後から合わせると空き土地が尽きる。
- 襲撃の失点はラウンド数×1点。防ぐ手数と失点を比べ、受けるならそれを上回る稼ぎを計画に書く。放置しない。
- 建物の種類ごとの上限（役所3軒など）を数えてから計画する。

## 資源と終盤
- 金・資材は終了時0点。第4ラウンドの終わりに、最終ラウンドの手の一覧と要る金・資材の合計を書き、収入を足して不足と余りが0に近くなるよう調整する。
- 最終ラウンドはワーカーと手札のプレイ枠が金より先に尽きやすい。金は第4ラウンドまでに建物に替える。
- 建設・カードの前に「所持−費用」を数字で書いて確かめる。手札に出る金額は割引後の値である。効果文の「1回ごと」「全体で1回」を確かめる。
- 空き土地と手札は最終ラウンドの燃料。第4ラウンドの終わりに残数を確保する。
- 最終ラウンドに打ちたい強い手を先に決め、その前提（空き土地・手札・解放条件・資源）を前のラウンドで用意する。計画は2〜3本の候補を持つ。

## 引き継ぎノートの定型（1.5KB 以内）
1. 最終ラウンドに打つ予定の上位3手と前提条件
2. このラウンドで用意する前提
3. 各軸の現在値→目標（ワーカー・インフラ・軍事・役所・商店／工房・空き土地・手札）
4. 他の席が狙っているもの（席ごと1行）
5. 前ラウンドの失敗1行（数値で確かめたものだけ）
