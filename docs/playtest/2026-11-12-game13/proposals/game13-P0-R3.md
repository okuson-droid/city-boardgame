# P0 R3 効率化の案
## 無駄だった場面
- wait のたびに選択肢20行＋選べない理由6行。大半は毎回同じ。
- 建築の下見を2回失敗（temp:N 抜け、大学以降は下見不可）。
- ref の actions・buildings を引き直した。
- 教練の count:0 を知らず move を2回に分けた。
## 変更案
1. wait の選択肢を「pioneer(n,u) export(n,u,t)…」の1〜2行にし、選べない理由は使用済み以外を省く。
2. 建築の下見は非公開の引きを除く確定分を出す。通常だけで足りるなら temp:0 を省略可に。
3. resume に建物・アクションの費用と残り上限を1行ずつ出す。
## 自分で変える
- ノートに全手順の ID（temp・count の段も）を書き、下見は分岐だけ。
- 最初に手順を決め、wait は出来事と狙いだけ見る。
