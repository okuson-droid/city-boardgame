# P2 R2 効率化の案
## 無駄
- 教練の count（払う段階→上昇回数）が分からず下見2回。
- 建築の下見4回：end が通らない（到達報酬の土地が挟まる）、temp:1 が通らない、--or 5通りで失敗。
- 移住は上限5/5で無意味と下見で知った。
## 変更案
1. 選択肢の行に要点：教練「金9→トークン8、Lv+1にトークン2」、遠征 reward:N の中身、移住「上限で増えない」。
2. 下見が途中で止まるとき、残る選択肢の ID を出す。
3. wait は番が来るまで待つ。指示書に「建築は temp・count なし」。
## 自分
- ノートの ID を使い、下見は比べ1回だけ。
- ref は --only。パス・ボーナス・襲撃を1回の move に。
