# P0 R4 効率化の案
## 無駄
- `temp:N` の要否が分からず3回やり直した（臨時0人なら不要）。
- `ref` 全文6KBを数行のために読んだ（不在のキャラクター6人分は不要）。
- 04 の能力と教練の2段 count の ID が分からず move を細かく分けた。
## 変更案
1. `temp:N` を省いたら通常優先で自動に埋める。
2. `ref --only actions|buildings` を足し、不在のキャラクターを既定から除く。
3. 狙いに plan:PCxx があれば、選択肢に達成できるマス（「D2 に住宅」）を出す。能力の ID を獲得時に1行出す。
## 自分で
- ノートに temp の規則と count の段を書いた。
- 初手で ref を読まず、迷う段だけ途中まで打って選択肢を見る。
- 撃退で土地が出るなら開拓より教練・最上位を先に考える。
