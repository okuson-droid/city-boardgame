# P2 R5 効率化の案
## 無駄
- ref 全文（約9KB）。要ったのは4行。
- resume・wait の選択肢36行と「選べない」。使うのは2〜3行。
- temp:N の段を知らず教練を4回に分け、下見も1回失敗。
- then-wait が「まだ番ではない」で戻った。
## 変更案
1. ref に --only actions:<名前> を足し、全文は呼ばないと指示書に書く。
2. wait の選択肢は狙い＋フリーアクション＋pass だけ。残りは「他N個」。
3. temp:N・払う量を省いたら既定で補い、1手番1回の move にする。then-wait は番まで待つ。
## 自分で
- 最初に下見4通りを1回呼び、全手番の順を決める。
- 実質無料の手（福祉Lv10、遠征・通常）を先に数える。
