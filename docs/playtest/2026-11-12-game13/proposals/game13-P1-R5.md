# P1 R5 効率化の案
## 無駄
- ID の型違いで下見2回が空振り（建築に count は無い、build:house）。途中まで本打ちして確かめた。
- カードの実コスト（大学割引は−1）と輸出の追加金（1回だけ）の誤算でやり直し、防衛を捨てた（−5）。
- ref 全文を読んだが要ったのは建物の上限と輸出・移住だけ。
## 変更案
1. 手札に割引後の金額、輸出・輸入に count ごとの受取額を出す。
2. 下見が「選択肢にない」で止まったら、その時点の選択肢 ID を出す。指示書の ID の型に build:house・order:N・space:sc:N#0 を足す。
3. knowledge に「通常ワーカーは獲得ラウンドに使えない」「インフラ上限12」を書く。
## 自分で
- 金が絡む手は1本の下見で最後まで確かめる。
- ref は --only で要る欄だけ。空きマスのボーナスは前ラウンドのノートに書く。
