# P1 R4 効率化の案
## 無駄
- ID の当て推量で下見を5回やり直した（plain→plains、temp:1 の要否、飯場のタイルの順と種類）。
- 軍事Lv4 に到達報酬があると誤解し、撃退に1個足りず土地4枚を逃した。
- ref 全文を読んだが要ったのは建物の表だけ。
## 変更案
1. 「選択肢にない」で止まったら、その段の選択肢 ID を出す。指示書の ID の型に地形名・order:N・raid:* を足す。
2. 教練の下見と show --only raid に「撃退まであと N 個」と次の到達報酬を出す。
3. ref --only buildings（表と残り軒数）。飯場の行にタイルの順と種類を書く。
