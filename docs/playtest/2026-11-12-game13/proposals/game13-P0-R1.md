# 効率化の提案 P0 R1
## 無駄だった場面
- 建築の下見を3回やり直した（temp:0・count:3 が出ない段だった）。教練は count:0 が要り、失敗→下見→やり直し。
- パス後のタイルの候補を見るために下見と pass を別に呼んだ。
- resume の全欄と候補ボード5枚の地図を読んだ（選べたのは3枚）。
## 変更案
1. move の失敗時に、止まった段の選択肢の ID を1行で出す。
2. 行動の選択肢に、パスで選べるボーナスタイルを1行添える。未解放の理由は変わったときだけ出す。
3. 資本家の定石に「工房3軒で輸出・最上位が R1 に開く」「手札と資材4で臨時ワーカー」を足す。
## 自分で変える
- 初めての型の手は、まず下見1回で段を確かめる。
- ボードは自分が選ぶ段になってから見る。
