# P0 R5 効率化の案
## 無駄だった場面
- ref 全文を読んだが、要ったのは福祉・移住・輸入と建物のコストだけ。
- 毎手番の選択肢の全一覧（約30行）。使うのは1〜2行。
- ID の誤り3回（count は0始まり、temp の要否、done）と非公開で止まる下見3回。
- 上限後の移住1回。
## 変更案
1. wait の選択肢は「狙い＋前回からの差分」だけ、全一覧は --options。
2. 自分1行に通常の「総数/上限」を出し、指示書の ID の型に count・temp の規則を足す。
3. ref の既定を自分に関わる欄（アクション・建物・変換）だけにする。
## 自分で変えること
- ref を読まず、要るアクションだけ下見する。
- wait の出力を捨てない。
- 金20＝臨時1人で最初に全手番を割り付ける。
