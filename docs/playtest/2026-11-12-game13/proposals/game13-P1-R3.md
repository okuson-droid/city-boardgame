# P1 R3 効率化
## 無駄
- 計画都市の置き方を手で探し、スクリプトを書いた（4回）。
- ID の外れ3回：開拓は count:4、建築は count なしで temp:N、plan は pioneer。
- resume と ref で公開カードが重複。ref のドラフト候補は不要。
- パス時効果がいま持つタイルと知らず4通り下見。
## 変更案
1. `plan --fit PC11`：新しく要る建物が最少の置き方を3件出す（上限超過は除く）。
2. ID で止まったらその段の ID 一覧を1行で出す。指示書に count と temp の順を書く。
3. ref はドラフト候補と resume の重複を省く。タイルに「パス時はいま持つもの」と書く。
## 自分
- ノートに ID の順を書いた。ref は --only actions,buildings。
- 教練は襲撃対策として先に打つ。
