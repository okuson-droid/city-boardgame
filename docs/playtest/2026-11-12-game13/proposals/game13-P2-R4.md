# P2 R4 効率化の案
## 無駄だった場面
- 行動の内側の選択肢（福祉の count、遠征の reward、建築の費用）が dry-run で見えず、1段ずつ打った（遠征5回、建築は undo 1回）。
- wait のたびに行動の全一覧と「選べないアクション」が出る。
- ノートの「遠征は臨時が自動」が誤りで報酬表を読み直した。
## 変更案
1. move --dry-run の最後に次の選択肢（ID・費用つき）を出す。
2. wait の行動の一覧を1〜2行に畳む。狙いのスペースだけ詳しく。
3. resume に置けるマスとマスボーナスを1行で足す。指示書に「撃退＝土地 ラウンド数枚」を足す。
## 自分で変えること
- 報酬・費用の ID をノートに書き、1手番を1回の move にまとめる。
- 建築の前に資材を換える。迷いは --or の1回で決める。
