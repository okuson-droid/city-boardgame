# P0 ノート（R4 終了）資本家・タイル7（パス時 種類1につき1点）
## R5（最終）の計画（金37 資材13 トークン2、通常6、手番は最後）
空き地 D2・B2・C1（平原）F3（森林）。商店・工房・役所は上限。砦2 大学2 住宅3 飯場0。
1. 最初の手番に `ability:sc:04#0 choose:1`（インフラ→Lv11）。
2. 福祉・最上位（資材6で+3、Lv12 で特別な市民、超過1段2点）。代わり：上位→通常。
3. 建築・最上位4軒：大学 B2（平原3点）・住宅 D2（PC03：工房D3−住宅D2−商店C2）・飯場 C1（7種類目、土地1枚無料）・砦 F3。
4. 住宅4軒で上限7→移住。余りは輸出→建築、開拓→住宅。
5. 襲撃：防衛ライン7・Lv5→トークン2で `raid:defense`（108 で+1点）。トークンを替えない。
6. 金・資材を使い切り、種類を増やしてからパス。
## 方針
- 建物1軒＝終了時に資材生産+1＝1点。臨時は得た手番に使えない。資材4→臨時1。
- プレイ済み6枚（大学3なら2枚1点）。
