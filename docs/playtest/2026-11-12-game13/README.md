## 減らなかった理由

1. **1手番を1回にまとめるようになった分、ID の推測の失敗が増えた。** 指示書に ID の型を載せたが、建物名（`house` を `housing` と書く）・地形名・`temp:N`／`count:N` の段がいつ要るかが分からず、打ち手は `--dry-run` で段ごとに確かめてから打った。下見が「選択肢にない」で止まっても、その段の選択肢が出ないため、もう一度推測した。
2. 打ち手の道具の呼び出しの1回ごとの文脈（CLAUDE.md・指示書・それまでのやりとり）が大きく、キャッシュの読み込みは呼び出しの回数でほぼ決まる。出力を縮めても、呼び出しの回数が同じなら読み込みは大きく減らない。

## 運用上の観察

- ラウンドの最初の選択が次の打ち手に回る件は、本局では報告がなかった（`--then-wait --round R` は番が来ればその場で打てるため）。
- `undo` を自分の選択の打ち直しに使った例（P2R3 で3回）。記録を見ると、他の席の手を巻き込んではいなかった。
