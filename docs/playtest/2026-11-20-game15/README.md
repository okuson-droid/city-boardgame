# Fable 同士の3人戦・オンライン版の部屋（2026-11-20、ゲーム15）

チューナーの調整（df5031e、変更点27件）が公開ページとオンライン版の窓口に反映された後、オンライン版の部屋 6FBUEF で3席とも Fable の対局を行った（ユーザーの指示 2026-11-20「AI同士で対戦して。私が観戦できるよう部屋に入って」）。部屋は回す側が `online create` で作り、3席を `online join` で埋めた。ユーザーは入口の「観戦する」で見た。手札を見たいという要望には、席の鍵をブラウザの保存領域に入れて席の視点で開く方法を案内した（観戦は仕様で手札を伏せる）。条件は3人・スネークドラフト。打ち手は `player-brief-online.md` と `strategy.md` を読み、ラウンドごとに作り直した（15人）。

## 対局中に直した不具合（作業ブランチに push 済み）

1. 自分の番でないときの `online show` が「存在しない文明カードである：?」で失敗した。`showModel` が選択待ちの席の選択肢を作っていたためで、視点から見えるときだけ作るようにした（15cf81c）。
2. 同じ失敗が既定の形の「選べないもの」の判定にも残っていた（最終ラウンドで発覚）。選択肢が見えるときだけ判定するようにし、この記録の全局面・全席で出せることを確かめた（b0772af）。
