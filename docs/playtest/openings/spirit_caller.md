# 精霊使い（spirit_caller）
版 91b12218。観察は f4ec8c2e の G4 と 26b2a3e9 の G11 の2局。
チップの回収は第2ラウンド（調整後）。終了時の点は隣の同じ種類の土地1枚1点（11-13 に2点から戻った。G11 のチップ20点は2点のとき）。
1. R1の狙い：土地タイル8・役所2・特別市民1
2. 手順（G4）：チップと土地→福祉・上位→建築・最上位（役所2・住宅、01）→輸入・上位→福祉・最上位→開拓・通常→パス
3. 代わり：建築・最上位→建築・上位。福祉は取り合いになる（G11 は3枠とも他席）
4. 効いた：資材なしでタイル、01＋森林（1枚2.5点）。足りない：建物（G11 は5軒）とインフラ。チップは地形ごとに1枚、建てないマスに
5. 根拠：G4 P1 128（3位）、G11 P1 119（2位）
