# 効率化の方法のまとめ（ゲーム12、Fable 15人分）

分類はゲーム10・11（`../2026-11-12-game10/proposals.md`・`../2026-11-12-game11/proposals.md`）に合わせた。人数は同じ趣旨の案を出した打ち手の数（15人中）。

| | 案 | ゲーム12 | ゲーム11 | ゲーム10 |
|---|---|---|---|---|
| A | `wait` の既定を「出来事・狙いの変化・自分の資源1行」（選択肢は id の1行か `--only options`）に縮める | 14人（P0R1〜R5、P1R1〜R5、P2R1・R3・R4・R5） | 10人 | 11人 |
| B | `resume` の短い形（第2ラウンド以降はドラフト候補・建物表・済んだ襲撃カード・効果文・履歴を省く。実測 約7〜25KB） | 12人（P0R2〜R5、P1R1〜R5、P2R2〜R4） | 12人 | 7人 |
| C | 下見が止まったら次の段の id と費用・不足を出す。下見できない選択肢にはその旨と効果文 | 6人（P0R4、P1R3、P2R2〜R5） | 7人 | 6人 |
| H | `move --then-wait`（end して次の番まで待ち、出来事と狙いの変化だけ返す）、`wait` の時間切れの見直し | 5人（P0R1・R5、P1R3・R4、P2R2） | 6人 | なし |

| D' | 1択の段（パスの後の襲撃の宣言が1つ・行動後の end だけ）を自動で進める | 3人（P0R2、P1R2・R4） | — | 6人（自動補完） |
| F | 選択肢に費用を出す（開拓の枚数ごとの資材、建築の必要額と不足「資材1足りない、先に金5→資材1」） | 4人（P0R1・R2、P1R1、P2R5） | 2人 | 4人 |

| E | 注意の追加：行動を打たずに `end`（P1R4） | 1人 | 4人 | 5人 |
| G | 定石：資本家の R1 手順（P0R1）、指揮官の遠征と最終ラウンド（P2R1・R5）、役所3軒＋移住（P2R4） | 4人 | 5人 | 3人 |

## 3局（45人）を通しての傾向

- A（`wait`）と B（`resume`）は3局とも上位2つで、モデル（Opus・Fable）とキャラクターが替わっても変わらない。ゲーム12では A が15人中14人。打ち手は既定の出力の代わりに `--only progress` や `head` で読んでおり、実測で `wait` の既定は約5KB、`--only progress` で約1/10（P0R5）。
- H（`end`・`wait`・次の手を1回の呼び出しに）は、打ち手の「自分で変えること」にも多く現れた（8人：P0R2、P1R1〜R3、P2R1〜R3・R5）。コマンドの側に `--then-wait` が無いため、打ち手は `move ... end; wait ...` をシェルでつないでいる。
- C・D・D' は、1手番を1回の `move` にまとめる指示が守られない原因（並べた選択肢は平均1.5〜2.0個）として3局続けて出た。
- 案の採否は、A・B・H が指示書 2026-11-11（軽量化）の既定の出力と `wait` の既定を変えるため、新しい指示書で扱う。
