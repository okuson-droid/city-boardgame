# P0 R2 効率化の案
## 無駄だった場面
- resume が全建物・全キャラ（ドラフト候補6人）・アクション全文を出し、wait/show も局面全体を再掲
- 建築を選んでから資材不足に気づき undo。dry-run は6個目で「非公開の情報」で止まり比べられず
- end 忘れで1回、04の能力が獲得手番に使えず1回、パス後の襲撃宣言（選択肢1つ）で2回、余分に呼んだ
## 変更案
1. resume：R2以降はドラフト候補・不変の効果文を省き、ノート＋局面＋選択肢だけ。wait は出来事と自分の行＋選択肢に絞る
2. move：行動後に残る選択肢が end だけなら自動で終える。襲撃の宣言が1択なら自動
3. 建築の選択肢に「4軒で金18・資材10、不足 資材1（先に金5→資材1）」のように必要額と不足を出す
