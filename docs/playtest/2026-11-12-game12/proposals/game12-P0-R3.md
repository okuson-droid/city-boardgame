# P0 R3 効率化
## 無駄
- resume が全キャラ・建物表・全襲撃カードを出した（約7KB）
- wait の後半（自分・他席・全選択肢）を毎回読んだ
- 開拓・教練・輸出の段の id が分からず1段ずつ move した（計8回）
## 変更案
1. resume：R2以降はドラフト候補・建物表・未公開の襲撃を省く（ref へ）
2. wait：既定を出来事・狙い・襲撃・置かれたスペース・自分1行に
3. 段の id（count:N・temp:N・tile:マス:種類・build:種類:マス・bonus:N）を知見のこつに1行
## 自分
- 1手番を1回の move に書く
- 占有型（福祉）を初手に
- wait の後は出来事だけ読む
