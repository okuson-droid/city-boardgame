# P2 R3 効率化の案
## 無駄だった場面
- resume が約9KB。ドラフト候補のキャラクター・全ボーナスタイル・全襲撃カード・建物表は R3 では不要
- reward の番号と end の要否、temp:N の段が分からず失敗2回・確認2回
- dry-run act:expedition:top は選択肢を出さず無駄
## 変更案
1. wait の既定を「出来事＋狙いの変化＋自分の1行」にし、局面と選択肢は --detail のときだけ
2. move が失敗したとき、その段の選択肢を出す。dry-run も適用後の選択肢を出す
3. resume を R2 以降は差分形に（自分のキャラクター・場のタイル・今回の襲撃だけ）
## 自分で変える
- ノートに次の手の完全な指定列（temp:N 込み）を書く
- end→wait→次の手を1回の呼び出しにつなぎ、出力は head/tail で切る
