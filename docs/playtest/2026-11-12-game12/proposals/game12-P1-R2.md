# P1 R2 効率化の案
## 無駄
- resume が全文で長い。要ったのは局面・自分・選択肢・計画都市だけ。
- 計画都市の当てはめを board から手で回転計算した。
- move が temp:0/1 と count:1 の段で止まり、呼び出しが3回増えた。wait は毎回全局面。
## 変更案
1. resume：R2 以降は局面・自分・狙い・選択肢だけ。効果文は ref。
2. 計画都市：未達成のカードに置ける当てはめ（マスと不足）を1行で出す。
3. wait は出来事と選択肢だけ。move は選択肢1つの段を飛ばし、内訳は --temp で指定。
## 自分で
- end・wait・次の手を1回の呼び出しに続ける。
- board は1回だけ読む。
