# P2 R5 効率化
## 無駄
- waitが毎回全局面＋選択肢32行（13回）。
- 段のID（temp・count・reward）が不明で1段ずつmove（約6回余分）。
- 下見が「増減なし」で止まる（福祉・遠征・大学・開拓）。
- 開拓の費用が見えず約10点を失った。
## 変更案
1. waitの既定を出来事・資源1行・選べない理由・注意だけにする。
2. 下見が止まるとき次の段のIDと費用を出す（例 count:0〜2 資材1/3/6）。
3. 定石に最終ラウンドを足す：遠征は臨時で回す、インフラ9は3点、資材を先に用意。
## 自分
- endと次の手を1回につなぐ。全員パス後はwaitしない。
- R5の全手を最初に列挙し、下見は建物の比較だけ。
