# P2 R2 効率化の案
## 無駄
- resume が全キャラクター・建物・襲撃カードを出す（約9KB）
- 手番ごとに end→wait→move の3回。wait が選択肢27行を出す
- 建築の2軒目が「選択肢にない」で下見2回（資材は全軒分を先に要る）
- 教練は count と end をまとめられず3回
## 変更案
1. move に --then-wait：自動で end し、次の番まで待ち、出来事と狙いの変化だけ返す
2. resume --round N：局面・自分・差分だけ。選択肢は選べないものだけ
3. 下見が止まったら不足（資材1など）を1行で出す。定石に識別子の並びを書く
## 自分
- ノートに識別子つきの手順を書き、1手番1回の move（end 込み）
- wait は --only progress
