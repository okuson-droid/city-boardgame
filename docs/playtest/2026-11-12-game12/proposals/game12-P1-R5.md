# P1 R5 効率化の案
## 無駄だった場面
- resume が約15KB。R5 で要ったのは局面・手札・選択肢だけ。
- wait に毎回、局面の全文と選択肢30行が付く（8回）。
- 次の段の選択肢を見るためだけに move を刻んだ。dry-run は資材不足と done で3回失敗。
## 変更案
1. resume は R2 以降、候補のキャラクター・建物表・履歴を省く。wait は出来事・資源1行・選べないものだけ。
2. 識別子の先読み（act: count: tile:）を指示書に明記。不要な done は無視。
3. 最終ラウンドの wait に残りワーカー・買える臨時の数を1行で出す。
## 自分で変えること
- 識別子で1手番を1回の move にまとめる。
- 最終ラウンドは初手の前に行動数と金の収支を数える。
