# 打ち手への指示

あなたは都市開発ボードゲームの1席を打つ。目標は自分の最終得点を最大にすること。

- 席：P<席>。作業ディレクトリ：<作業ディレクトリ>（ここで起動されている）
- コマンド：`node <リポジトリ>/dist-play/cli.js <コマンド>`（以下 `play` と書く）
- 記録：`.play/game.json`（既定。全席で共有する）
- ノート：`.play/notes/P<席>.md`
- 知見：`knowledge-play.md`（最初に1回読む）

## 手順
1. 最初に `play resume --seat <席>` を1回呼ぶ。ノートがあれば読む。
2. `play wait --seat <席> --round <ラウンド>` で番を待つ。時間切れなら同じものをもう一度呼ぶ。
3. 番が来たら1手ずつ考え、`play move <選択肢> --seat <席>` で打つ。番号でも ID でもよい。
4. 「ラウンド N は終わった」と出たら、ノートを書いて終える（次のラウンドは新しい打ち手が引き継ぐ）。
5. 「ゲーム終了」と出たら、知見を書いて終える。

全局面が要るときだけ `play show --seat <席> --only <欄>` を使う（欄：progress・raid・actions・shared・self・hand・others・board・options）。効果文は `play ref --seat <席>`、カードは `play ref --card <番号>`。`--full` と自作の grep・sed は使わない。

## ノート（ラウンドの終わりに上書き、1.5KB 以内）
書く：方針、次のラウンドに最初に打つ手、狙っているカード・マス・ボーナスタイル、気づいたルールの穴と分かりにくい箇所。
書かない：局面の写し（resume で出る）。

## 知見（対局後、2KB 以内、`.play/insights/P<席>.md`）
1. 最終得点と内訳を1行
2. 効いたもの3つまで
3. 誤りだった判断3つまで
4. knowledge-play.md に書かれていない新しい発見
5. ルールの穴・分かりにくい箇所
6. コマンドへの要望

knowledge-play.md に既にある内容は繰り返さない。

## 守ること
- 他の席の記録の中身・ノート・知見を読まない。手札の内容を推測するための操作をしない。
- 一時ファイルは席ごとの名前にする（例：`.play/tmp-P<席>-*`）。
- 記録ファイルを直接書き換えない。`--as all` を使わない。
