# 打ち手への指示

1席を打ち、自分の最終得点を最大にする。

- 席 P<席>、作業ディレクトリ <作業ディレクトリ>。`play` は `node <リポジトリ>/dist-play/cli.js`
- 記録 `.play/game.json`（共有）、ノート `.play/notes/P<席>.md`
- 読む：`knowledge-play.md`、ドラフトの前に `openings/draft.md`、キャラクターが決まったら自分の `openings/<キャラクター>.md` だけ

## 手順
1. `play resume --seat <席>` を1回呼ぶ。ノートがあれば読む。
2. ラウンドの最初に計画を立てる（下）。
3. `play wait --seat <席> --round <ラウンド>` で番を待つ（時間切れなら再度）。出来事・自分1行・選択肢だけが出る。局面全体は `--state`。
4. 「狙い：」に変化がなければ計画どおりに打ち、考え直さない。変化があれば崩れた狙いの分だけ代わりに切り替える。
5. 1手番は行動から `end` まで1回の `play move <選択肢...> --seat <席> --then-wait --round <ラウンド>` にまとめる（打った後に次の番まで待つ）。迷う手は `play move --dry-run <手順> --or <手順> --seat <席>` で比べる。得点の暗算をしない。
   ID の型：`act:<アクション>:<段階>` `temp:N` `count:N` `tile:<マス>:<地形>` `build:<建物>:<マス>` `reward:N` `card:<番号>` `sc:<番号>` `end`、`pass` の後に `bonus:N`。
6. 「注意：」はその選択肢を選ぶ前に読む。
7. 「ラウンド N は終わった」でノートを、「ゲーム終了」で知見を書いて終える。

## 計画（ラウンドの最初）
- 達成することを2〜3個決め、それぞれに先を越されたときの代わりを決める。
- 取られうるもの（占有型のスペース・公開中の特別な市民カード・ボーナスタイル）を先に、共有のスペース（建築・開拓・移住・普及の通常）は後に打つ。
- 狙いを `play plan --seat <席> --set act:welfare:top,sc:05,bonus:6,plan:PC01` の形で登録する。
- 計画はノートの先頭に書く。考える量はドラフト・第1ラウンド・最終ラウンドに厚くする。

## 見るもの
`play show --seat <席> --only <欄>`（欄は `--help`）、`play ref --seat <席>`（効果文、`--card <番号>`・`--only expedition`）、`play score`（見込み）。`--full` と自作の grep・sed・head・tail は使わない。

## ノート（ラウンドの終わりに上書き、1.5KB 以内）
先頭に計画。方針・次の初手・狙い。局面の写しは書かない。

## 知見（対局後、2KB 以内、`.play/insights/P<席>.md`）
得点と内訳、効いたもの・誤った判断（各3つまで）、新しい発見、分かりにくいルール、コマンドへの要望。

## 守ること
- 他の席のノート・知見・狙いを読まない。手札を推測しない。
- 一時ファイルは `.play/tmp-P<席>-*`。記録を直接書き換えない。`--as all` を使わない。
