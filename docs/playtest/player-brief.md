# 打ち手への指示

都市開発ボードゲームの1席を打ち、自分の最終得点を最大にする。

- 席 P<席>、作業ディレクトリ <作業ディレクトリ>。`play` は `node <リポジトリ>/dist-play/cli.js`
- 記録 `.play/game.json`（共有）、ノート `.play/notes/P<席>.md`
- 読む：`knowledge-play.md`、ドラフトの前に `openings/draft.md`、キャラクターが決まったら自分の `openings/<キャラクター>.md` だけ

## 手順
1. `play resume --seat <席>` を1回呼ぶ。ノートがあれば読む。
2. ラウンドの最初に計画を立てる（下）。
3. `play wait --seat <席> --round <ラウンド>` で番を待つ（時間切れなら再度）。
4. 「狙い：」に変化がなければ計画どおりに打ち、考え直さない。変化があれば崩れた狙いの分だけ代わりに切り替える。
5. 1手番の選択は、決まっている限り1回の `play move <選択肢...> --seat <席>` にまとめる。迷う手は `play move --dry-run <手順> --or <手順> --seat <席>` で比べる。得点の暗算をしない。
6. 「注意：」の行は、その選択肢を選ぶ前に読む。
7. 「ラウンド N は終わった」でノートを、「ゲーム終了」で知見を書いて終える。

## 計画（ラウンドの最初）
- 達成することを2〜3個決め、それぞれに第1候補と、先を越されたときの代わりを決める。
- 占有型のスペース・公開中の特別な市民カード・ボーナスタイルは取られうる。それを先に、共有のスペース（建築・開拓・移住・普及の通常）は後に打つ。自分より先に打つ席を見て初手を決める。
- 狙いを `play plan --seat <席> --set <狙い,...>` で登録する（act:<アクション>:<段階>・sc:<番号>・bonus:<番号>・plan:<番号>）。
- 計画はノートの先頭に書く。考える量はドラフト、第1ラウンドの計画、最終ラウンドの使い切りに厚くする。

## 見るもの
`play show --seat <席> --only <欄>`（progress・raid・actions・shared・self・hand・others・board・options）、`play ref --seat <席>`（効果文、`--card <番号>`・`--only expedition`）、`play score`（見込み）。`--full` と自作の grep・sed は使わない。

## ノート（ラウンドの終わりに上書き、1.5KB 以内）
先頭に計画。方針・次の初手・狙い・ルールの穴。局面の写しは書かない。

## 知見（対局後、2KB 以内、`.play/insights/P<席>.md`）
最終得点と内訳、効いたもの・誤った判断（各3つまで）、knowledge-play.md と openings にない発見、分かりにくいルール、コマンドへの要望（使わなかった機能も）。

## 守ること
- 他の席の記録の中身・ノート・知見・狙いを読まない。手札を推測する操作をしない。
- 一時ファイルは `.play/tmp-P<席>-*`。記録を直接書き換えない。`--as all` を使わない。
