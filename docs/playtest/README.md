## 手順

1. ビルドする：リポジトリで `npm run play:build`。`dist-play/cli.js` ができる。
2. 作業ディレクトリを用意する：リポジトリの外に1つ作る（例：`/tmp/play-<日付>/`）。全席がこのディレクトリで起動し、記録 `.play/game.json` を共有する。リポジトリの外で起動するのは、リポジトリの CLAUDE.md（実装向け）を打ち手に読み込ませないためである。ただし、同じセッションから Agent で起動した打ち手には CLAUDE.md が自動で入る（2026-11-11 の確認）。このため CLAUDE.md は約7KB に縮め、領域ごとの約束事を `docs/dev/` に分けた。
3. `player-brief.md`・`knowledge-play.md`・`openings/` を作業ディレクトリに写し、`player-brief.md` の `<席>`・`<作業ディレクトリ>`・`<リポジトリ>` を埋める。
4. 対局を作る：作業ディレクトリで `node <リポジトリ>/dist-play/cli.js new --players 3 --seed <シード>`。
5. 席ごとに打ち手を起動する：作業ディレクトリを起動場所にし、`player-brief.md` を指示として渡す。「いまのラウンド R」を添える（ドラフトと準備は第1ラウンドに含める）。
6. ラウンドごとに作り直す：打ち手は `wait --round R` が「ラウンド R は終わった」と出したらノート（`.play/notes/P<席>.md`）を書いて終える。回す側は R＋1 を渡して新しい打ち手を起動し、新しい打ち手は `resume --seat <席>` とノートから続ける。会話の履歴は持ち越さない。狙い（`.play/plan-P<席>.json`、`plan --set` で打ち手が作る）は消さずに残す（ラウンドの途中で作り直したときも、前の打ち手の狙いと知らせ済みの状態を引き継ぐ）。
6-2. 効率化の方法を出させる（ユーザー決定 2026-11-12）：起動するときの指示に、終える前に `.play/proposals/P<席>-R<ラウンド>.md`（1KB 以内）を書くことを添える。中身は、同じ得点をより少ない読む量・呼び出しで出すための方法で、(1) そのラウンドで読む量や呼び出しが無駄だった具体的な場面、(2) コマンド・指示書・定石への変更案（3つまで、どの出力をどう変えるか）、(3) 自分で次から変えるやり方。回す側は対局後に席とラウンドをまたいで集め、重なった案と根拠を `docs/playtest/<日付>/proposals.md` にまとめる。
7. 対局後に `openings/` を見直す：新しい観察で第1ラウンドの手順や先を越されたときの代わりが変わったキャラクターは、そのファイルを直し、根拠の対局（ゲーム番号・席・得点）を足す。データの版が変わっていれば、変わった数値に関わる記述を調べ直す。1ファイル1KB を越えたら古い観察を削る。
8. 対局後に回収する：`.play/game.json` を `docs/playtest/<日付>/replays/` に、各席の知見（`.play/insights/P<席>.md`）を `docs/playtest/<日付>/insights/` に、効率化の方法（`.play/proposals/`）を `docs/playtest/<日付>/proposals/` に置く。`knowledge-play.md` は回す側がまとめて更新する（3KB を越えたら古い内容を削るか統合する）。経緯は `docs/playtest/<日付>/` に別に書く。

## コマンドの要点

- 既定の出力は短い形である。`move` は出来事・自分の要約・次の選択肢だけ、`wait` は他の席の手番を1行ずつと局面を出す。
- 得点の見込み（`score`・`resume`・`show --only self`）は終了時の能力を含む。`move --dry-run`（`--or` で最大4通り）は記録を変えずに増減と見込みの増減を出す。選択肢の後の「注意：」は過去に失点になった型の事実、「狙い：」は `plan` で登録した狙いの状態の変化である。
- 対局中に変わらない文言は `ref`、手札の効果文は `show --only hand`、カードは `ref --card <番号>`。
- 従来の全文は `--full`。打ち手には使わせない（使ったなら、既定の形に足りない情報があったということである）。
- 出力量は `npm run -s play:measure -- --file <記録>` で数える（近似）。

## 確かめていないこと
