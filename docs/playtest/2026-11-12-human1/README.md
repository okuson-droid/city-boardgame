# 人と Fable の対局（2026-11-12、オンライン版の部屋 FVLNZZ）

ユーザー（オクソン）と Fable 2席の対局である（ユーザー決定 2026-11-12「1と2を直したら、私が fable と対戦する」）。人は公開ページのオンライン版で打ち、Fable はリポジトリの外の作業ディレクトリから `online` のコマンドで席に入った。打ち手の指示は `docs/playtest/player-brief-online.md`。ラウンドごとに打ち手を作り直し、各打ち手に効率化の方法を出させた。最初の部屋（5C3SR2）はユーザーの指示でやり直した（ドラフトの前に確かめる窓を求められ、画面に足したが、公開ページは main から作られるため本局には入っていない）。

## 得点

| 順位 | 席 | キャラクター | 最終 | 内訳（基礎／経済／文化／生活／自然／軍事／その他） |
|---|---|---|---|---|
| 1 | P1 Fable-A | 学者（ボード3・タイル8） | **313** | 43／25／63／112／0／-3／73 |
| 2 | P0 オクソン（人） | 聖女（ボード1・タイル1） | 251 | 55／27／36／32／36／-2／67 |
| 3 | P2 Fable-B | 英雄（ボード4・タイル10） | 159 | 30／15／12／48／0／30／24 |

- Fable-A の313点はこれまでの全対局の最高である。特別市民03（プレイ済みのカード1枚につき点、42枚で72点）・大学3軒・普及・最上位の組み合わせで、学者の調整（学術カードの追加能力）が効いた。
- 人は基礎55（土地19・建物26・通常ワーカー10）と自然・環境36（計画都市3枚を1位、自然公園15）で、3席で最も幅広く取った。最終ラウンドに普及・通常を10回続けて手札を出し切った（Fable-B の観察）。
- Fable-B は最終ラウンドに空き土地と手札が尽き、商店3軒目に金2足りず金18を残した。

## 対局中に直した不具合（いずれも作業ブランチに push 済み）

1. `online move --dry-run` が `--dry-run` を無視して手を送っていた（Fable-A の R1 で開拓・通常が実際に打たれた）。何も送らずに下見するようにし、`online ref` を加えた。
2. オンライン版の伏せた写しで、下見・注意・見込みが伏せた情報（他の席の手札）に触れて「存在しない文明カードである：?」で失敗した。下見はそこで止め、注意と見込みは省く。
3. 次のラウンドの最初が自分の番のとき、`online wait --round` が「ラウンドは終わった」を出さなかった。ラウンドの終わりを番より先に見る。
4. `ref --only ids` の遠征の報酬の ID を「レベル」と書いていた（実際は報酬表の添字）。

## 運用上の観察

- 第5ラウンドの Fable-A が、番待ちをシェルのループ（`for ... sleep`）で組み、道具の上限（約120秒）で裏に回ったまま番に気づかず止まった。打ち手を作り直して解消した。人の手番は数分かかるため、`online wait` の100秒では「まだ番ではない」の呼び直しが多い（Fable-B の R5 で約10回）。
- オンライン版では `plan`（狙い）と `score` が使えない。
