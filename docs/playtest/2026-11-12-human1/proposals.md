# 効率化の方法のまとめ（人との対局、Fable 10人分）

| 案 | 人数 |
|---|---|
| 番待ちを1回の呼び出しで済ませる（`wait --until-turn`・`--then-wait` が番かラウンドの終わりまで中で待つ、または `--timeout` を長く）。人の手番は数分かかり、100秒の待ちでは呼び直しが多い | 10人（全員） |
| 番が来たときの選択肢を、前回からの差分（消えた・増えた）だけにし、「選べない〜」の欄は既定で省く（`--why`・`--options` で出す） | 7人（A-R2・R4・R5、B-R1・R3・R4・R5） |
| `online ref` と `online move --dry-run`（本局の途中で加えた） | 2人（A-R1、B-R1） |
| `ref` を欄ごとに絞る（ドラフト候補・他席の特別市民・プレイ済みの効果文を既定から外す） | 3人（A-R3、B-R4・R5） |
| 1択の段（`count:1`）を online でも自動で飛ばし、自動で確定した段の後の `done` を読み飛ばす | 2人（A-R2・R3） |
| 下見で次の段の選択肢の ID と内容を出す、手番をまたいだ金・資材の過不足を下見する | 2人（B-R2・R5） |
| 効果文の「追加で得る」が1回ごとか全体で1回かを書く（輸出・最上位の読み違い） | 1人＋知見（A-R5） |

## 回す側の所見

- 最多の「中で待つ」案は、打ち手の道具の上限（約120秒）と食い違う。上限を越える待ちは道具の側で裏に回り、本局の停止（README）を起こした。中で待つなら、道具の上限より短い間隔で「まだ」を返し続ける今の形を保ち、呼び直しを指示書で明記する（ループを自作させない）方が安全である。人との対局に限り、回す側が待ってから打ち手を起こす運用も考えられる。
- 選択肢の差分（7人）は、ゲーム13の A'（7人）と同じ趣旨で、2局続けて出た。
