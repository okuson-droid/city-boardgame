# 効率化の案 Fable-B R5
1. 番待ちを1回の呼び出しで済ませる：`online wait --until-turn`（上限つきで自分の番まで戻らない）。今回は「まだ番ではない」の呼び直しが約10回あった。
2. ラウンドの計画を1回の下見で通す：`move --dry-run --plan <手番1> / <手番2> / ...` で、手番をまたいだ金・資材・ワーカーの過不足と見込みを出す（相手の手は無いものとする）。今回は金2の不足に5手番目で気づいた。
3. wait の「選べないアクション」の欄を既定で省く（`--why` で出す）。毎回10行前後で、読む量の約3分の1。
4. ref を欄ごとに出す既定にする（`ref` だけなら見出しの一覧）。全文は1回で約12KB あり、使ったのは遠征の表・建物・福祉の3欄。
5. 最終ラウンドは「残る金・資材で届く点」の候補を show に1行出す（臨時ワーカーの購入を含む）。
