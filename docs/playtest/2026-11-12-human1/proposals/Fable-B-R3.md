# 効率化の案 Fable-B R3
無駄だった場面：
- 行動を選ぶ段の選択肢と「選べないアクション」が毎手番30行ほど出る。6手番で同じ文を6回読んだ。show --only options と actions を続けて呼ぶと選択肢が2回出た。
- reward:10 と書いて失敗（報酬表はレベル表記、ID は添字）。1回余計に呼んだ。
- move --then-wait が「まだ番ではない」で返るので wait のループを自分で重ね、番が来ていたときは同じ出力を2回読んだ。
変更案：
1. 行動を選ぶ段は、前の手番から変わった選択肢（消えた・増えた）と「選べない」の差分だけを出す。全部は show --only options。
2. ref --only expedition の各行に ID（reward:0〜4）を添える。reward:<レベル> も受け付ける。
3. --then-wait は番が来るかラウンドが終わるまで内部で待ち続ける（--timeout で打ち切り）。指示書の「もう一度呼ぶ」を無くす。
