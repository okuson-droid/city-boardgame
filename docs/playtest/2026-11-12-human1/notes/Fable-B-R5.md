# 計画 R5（確定版・英雄）
資材19相当（金5→資材1 込み）を使い切る。順：
1. 福祉・上位（資材3、+4点、臨時+1。替えない）※取られたら最上位 count:1 か通常
2. 遠征・最上位 reward:2×2（水場 D4・D5 に無料タイル）＋reward:4×2（4点）
3. 開拓・通常：山岳タイル2枚（C4・A4、資材6）
4. 教練・通常（金3）→Lv12 で山岳に工房を無料（撃退もトークン0に）
5. SC09 のスペース：山岳に工房（無料）
6. 臨時を資材4で買い、建築・通常：水場に商店2（金10・資材6）
結果：工房3・商店3で SC05 +8、SC07 +4、収入の点 +11。
覚え：遠征のタイルは地形と同じ種類だけ・無料。山岳を他の地形に置くと資材3。建設の報酬は空き土地がないと出ない。
