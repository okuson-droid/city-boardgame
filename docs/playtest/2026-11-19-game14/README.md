- 3席とも、手引きで禁じた自作の絞り込み（grep・tail）を1〜2回使った（P1 の R3、P2 の R5）。`show`・`resume` の出力から目当ての行を探しにくいことを示す。部屋 DFKAGB の対局（`../2026-11-13-human2/`）でも同じだった。
