# P1 知見（聖女、1位 218点）
1. 合計218：基礎45 経済・産業16 文化・学術22 生活・福祉98（SC01 26・SC02 22・SC05 16・インフラ超過14・役所3で1人2点）その他38 軍事-1。P0 169、P2 138。
## 効いたもの
- SC02（最上位の度に2点）＋SC01（森林タイルの度に2点）の重ね掛け。開拓最上位で森林を置くと1手で6〜10点。
- 聖女で通常ワーカー10を早く満たし、住宅10・役所3・大学3を上限にして SC05（上限の種類×4点）。最終ラウンドに工房2軒で3種目→計16点。
- 美術タグのカード（028・032・027）は大学3軒で実質安く、資材5ずつ返ってくる。最終ラウンドの資材源として強い。
## 誤りだった判断
- R5 で資材2のまま建築・上位を先に取り、3軒目が建てられず自動で確定した（資材を先に作るべきだった）。
- 商店を2軒止まり（SC05 の4点と換算率を逃した）。建築の枠が足りなかった。
## 新しい発見
- 建築・上位で資材が足りなくなると、残りの軒数を選ばせずに確定する。資材の見込みを先に作る。
- 文明カード自身の「1点」は終了時の内訳に別には出ない。
- 森林の土地タイルは開拓で地形の違うマスにも置ける（追加コスト）。SC01 持ちは森林の空きマスが尽きても続けられる。
- 最終ラウンドの残り資材は、資材4→臨時ワーカーにして最上位アクション（SC02の2点）に回すと得点になる。
## ルールの穴・分かりにくい箇所
- 同じアクションの別の段を1人が使えるか（上位の後の通常）が表示から分かりにくい。資金不足で通常が選択肢から消えるのと区別がつかない。
## コマンドへの要望
- 選択肢から消えた行動に「なぜ出ないか（資源不足・取られた・同じアクション）」を1行で出してほしい。
