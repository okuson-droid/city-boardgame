3. 誤りだった判断

4. 新しい発見
- 1回の建築で同じ種類の建物は1軒だけ（役所2軒を同時に選べない。住宅は未確認）。

- 引継ぎ（055）の中のプレイは普及最上位の2金割引が効かない。
- 最終ラウンドの収入は R5 開始時のボーナスタイルの処理の後に入る。
- 資材0では開拓が選択肢に出ない。フリーアクションで資材を作ると出る。
5. ルールの穴・分かりにくい箇所
