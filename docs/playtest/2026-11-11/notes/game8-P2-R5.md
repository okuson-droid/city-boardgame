# P2 学者 ノート（R4終了時）
## 方針（最終R5）
建物の種類6（商店・工房・砦・役所・大学・住宅）。SC08で終了時に種類×1点。飯場を建てれば種類7。残った金・資材は点にならないので使い切る。
## R5 の最初の手
- ability:sc:17#0（臨時1）→ 普及・最上位（W2、1枚ごと-2金）で手札を最大4枚：051街並み（建物3につき1点）、045研究支援（大学3→資材9）、030フラウス（美術、資材3+2）、055引継ぎ（1枚引いて1枚プレイ）。プレイ3枚ごとに学者の能力（インフラ超過で2点 か 臨時1）。
- SC11専用スペース（W2）で普及・最上位や福祉・最上位を写せる（占有なし、解放条件なし）。福祉・最上位は資材6→インフラ+3＝6点。**写す前に資材を必要数そろえる**（足りないと自動で安い組になった）。
- 福祉・通常（資材1→2点）も強い。建築は飯場（種類+1）と住宅。
## 襲撃R5
カード4：防衛ライン7・撃退12（累積）。軍事Lv3→防衛はトークン4（所持1）、撃退は9。教練・通常で3得られる。失敗は-5点。
