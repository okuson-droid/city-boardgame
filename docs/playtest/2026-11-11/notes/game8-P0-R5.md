# P0 ノート（R4終了、英雄）
## 方針（R5＝最終、手番は最初。金・資材を使い切る）
軍事Lv12・砦3。役所3・大学3は上限。特別市民07（山岳の建物2点）・06（水場の建物2点）・20（取得済み）。
経済・産業が大きい：工房3軒で資材収入1＝1点（いま工房1・収入9）、商店3軒で金収入3＝1点（商店1・収入30）。工房2・商店2を足すのが最優先（約＋20点）。
## R5の手順（収入 金30・資材9、通常7人、タイル10でLv9→土地2枚）
1. 開始の土地2枚：C2・E7（水場）。空きはA2（山岳）・A7（水場）・B6・A8（森林）。
2. 建築最上位を最初に（4軒 金18・資材10）：工房A2、工房、商店A7・C2。不足は金5→資材1、038を捨てる。
3. 教練最上位：金3、上昇3回＝6点。
4. 遠征最上位：2点×2＋建設の権利×2（金5・資材3）か資材。遠征通常：2点＋権利。
5. 余り：福祉最上位（資材6でLv12、場の12＝住宅1軒1点）。
## 気づき
- 遠征Lv7「建設の権利」は建築なしで1軒（値引きなし）。
- 福祉最上位の臨時2人は次の手番に使えた。
- 砦でLv12超は点なし。パス時のタイルは持ち替え必須。
- 収入は開始時のタイル配置の後。
- 自然公園いま5点：建てると崩れうる（score で確かめる）。
