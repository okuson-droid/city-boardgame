# P1 ノート（R4 終了時）
## 方針（最終ラウンド R5、手番順 P0→P2→P1）
聖女：通常ワーカー10/10（聖女の SC 取得済み）。役所3（1人2点）・住宅10・大学3＝上限。SC05：上限の種類1つにつき4点。SC02：最上位の度に2点。SC01：森林タイルの度に2点。ボーナスタイル7：パス時に建物の種類×1点（いま6種、砦で7）。
## R5 に打つ手
- 金・資材を使い切る。SC15 の起動（2枚引く）を忘れない。
- 普及最上位で美術3枚 028→032→027（美術タグ1・2・3点＋資材5・5）と 080/079。
- 建築最上位を早めに（R4 は取られた）。商店・工房・砦・飯場を足す。空きタイル A3・A4（森林）。飯場 B7 の隣は資材-1。
- 開拓最上位で森林（A2・E3）。SC14・SC09 の専用スペースも使う。
- 雲隠れ：襲撃は raid:skip。
## 気づいた点
- 同じアクションは1人1段だけ（建築・通常の共有は2回使えた）。
- 資材が足りないと建築・開拓は選択肢に出ない（カードを捨てると出る）。
- 公共事業は資材が尽きると残りを自動で終える。
