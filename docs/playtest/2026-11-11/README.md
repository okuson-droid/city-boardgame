### 減らなかった理由

1. **ゲーム5〜7の打ち手は、すでに自分で出力を絞っていた。** ゲーム5の `move` の結果は1回平均783字で、ほぼすべてに grep・sed を付けていた。今回の既定の `move` は1回平均780字で、絞り込みなしで同じ大きさになった。`play:measure` は絞り込みのない全文と比べていたため、効果を大きく見積もった。
2. **作り直しで、引き継ぎの読み直しが増えた。** `resume` は15回で12.3万字（1回平均8,200字）だった。打ち手ごとに brief・knowledge-play.md・ノートも読み直す。
3. **CLAUDE.md が打ち手に読み込まれていた。** 打ち手をリポジトリの外の作業ディレクトリで動かしたが、このセッションから起動した打ち手には CLAUDE.md が自動で入っていた（最初の呼び出しの文脈が約9万トークン）。道具の呼び出しのたびにこの文脈を読み直すため、キャッシュの読み込みの大部分を占める。指示書 3-2 の狙い（CLAUDE.md を読ませない）は、この起動の仕方では果たせない。
4. **呼び出しの回数が増えた。** 選択肢を1つずつ送る打ち手が多く、`move` は343回から443回に増えた。

一方、道具の結果の内訳は次のとおり変わった：ゲーム5は `move`・`wait`・`show` のほぼすべてが自作の絞り込み付き、今回は既定の出力のまま使い、絞り込みは27回（全体の約5%）だった。

## 既定の出力に足りなかったもの（`--full` と自作の絞り込みの使われ方と、打ち手の要望から）

- ドラフトで個人ボードの中身が見えない（地図は `--board` で出るが、案内していなかった）。
