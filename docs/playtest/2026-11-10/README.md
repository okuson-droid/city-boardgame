# 対話プレイによる対局の記録（2026-11-10）

対話プレイ用のコマンド（`tools/play/`）を使い、エージェント3人（Fable 5.2 が1人、Opus 5.5 が2人）が1局を席ごとに打った記録である。目標は1人100点以上とした。

| ファイル | 内容 |
|---|---|
| `replays/game1.json`〜`game7.json` | 各ゲームの記録（リプレイ）。トップページの「記録を再生する」で読み込める。`npm run -s play -- show --file docs/playtest/2026-11-10/replays/game1.json` のようにコマンドでも読める |
| `knowledge.md` | ゲームを重ねて積み上げた通しの知見（勝ち筋・キャラクターの評価・バランスの気になる点・コマンドのこつ） |
| `comparison-fable-vs-opus.md` | ゲーム5〜7のモデルの比較（同じシード・同じキャラクターで Fable の席を回した） |
| `insights/gameN-PK.md` | 各ゲーム・各席のプレイヤーが提出した知見 |

記録はゲームのデータの版（`dataVersion`）を持つ。データを変えた後に読み込むと、再生の画面は警告を出し、選べなくなった手の手前で止まる。

記録は、対局の後に main で特別市民10 の2枚目のプレイが処理順を尋ねない形（`later`）に変わったため、いまのデータで再生できるよう直してある。処理順の選択（`order:`）を取り除き、ゲーム7の365〜371手目は「無料の1枚（100）→その土地タイル→通常のコストの1枚（085）」の順に並べ替えた。7局とも最終得点は当時と一致する。
