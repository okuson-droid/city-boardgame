## 3. 強い路線・カード・アクション／弱いもの

- **福祉最上位**（資材6でインフラ+3）。インフラ4・8・12の特別市民に2アクションで届く。12以降も資材1→2点（通常）、資材3→4点（上位）で、役所3軒なら臨時ワーカー→資材4の変換が付き資材は中立に近い。
- **sc14**：獲得時3枚（任意の種類）＋毎ラウンド2枚で、計11枚＝資材22相当。A8（特別市民のマス）へ伸ばすのにも使えた。
- **sc10 と 003公共事業・045研究支援・058天然資源**。無料プレイは高いカードほど得。sc10 は「有料の1枚」を先に処理して資材を作り、無料の1枚に回せる（033→003）。
- **計画都市**（7点＋特別市民）。形は回転だけ（鏡像なし）なので軸座標で確かめてからタイルの種類を決める。開拓アクションなら地形と違う種類を置ける（C5 に水場）。
- **最終ラウンドの資材の使い道**（資材1あたり）：森林タイル＋sc01＝2資材で2.5点、自然公園の3枚組＝資材5で8点、2枚組＝資材2で3.5点、福祉の超過＝資材1で2点。資材4→臨時ワーカーも R5 に3回使った（ワーカーが先に尽きたため）。
- **建築・通常の連打**：共有で1人2軒。最上位・上位を取られても、人手あたりは通常のほうが良い（割引は金1〜2・資材1〜2だけ）。
- P2 の芸術家＋sc03（カード1枚2点、獲得時にプレイ済み枚数ぶん）＋sc02＋タイル8 は、カード22枚で200点。建物16軒でも届く別の勝ち筋。

## 4. ルールの穴・分かりにくい箇所・バランス
- **特別市民が多すぎる・連鎖する**：1人で7枚（聖女2、インフラ3、A8のマス1、計画都市1）。終了時の3枚（05・12・06）だけで44点、01を足すと58点。インフラの到達報酬は福祉最上位2回（資材12）で4→12に届き、安すぎる疑い。
- **sc13 が聖女と重なると強すぎる**：無料住宅2＋移住最上位の3人を即使用で、そのラウンドの行動が実質+4。
- **資材4→臨時ワーカー**が最終ラウンドの行動数の上限を外す（P0・P2 も使った）。ワーカー配置の制約が弱まる。
- **福祉の超過**（資材1→2点）＋役所3軒の変換（臨時→資材4）は、インフラ12以降ほぼ無償で点になる。占有型なので先に取った者勝ち。
- **ボーナスタイル6**は住宅10軒で毎回10点。パスの早さだけで決まり、差が大きい（タイル8もプレイ済み22枚で11点）。
- **襲撃を無視してよい**：5回失敗で-15点。212点に対して小さい。P2 は雲隠れ1枚で3回分を飛ばした。
- **経済が収入だけで決まる**ので、最終ラウンドの残りの金・資材は使い切るしかない。商店3軒の「輸入のたびに金生産+3」は最終ラウンドだと輸入1回＝1点。
- 分かりにくい点：(a) 通常ワーカーの上限が住宅数で決まることは局面の表示（上限5）から気づいた。(b) 最終得点の内訳で、特別市民05・06・01 は「生活・福祉」、12 は「その他」に入る。(c) 得点の見込みの基礎の「土地」は2枚で1点（奇数の1枚は0点）。(d) 上位・最上位の福祉で、変換できる臨時ワーカーを持っていないときは変換の問いが出ない。(e) 自然公園は「建物のない土地タイルの種類」で数えるので、最後に空きタイルを合わせて作れる（地形でなくタイルの種類）。

## 5. 対話プレイ用コマンドの使い勝手
良い点：
- `wait` が前回からの出来事と局面を一度に出すので、1手ごとの判断に足りた。`score` の終局前の見込みは最終ラウンドの比較に役立った（P2 と競っていることに気づけた）。
- 選択肢のラベルにコストと効果が出る（「金15 → 資材6」「地形と異なる」「マスボーナス」）。自然公園の欄の「いま終わったら何点」はタイルを置いた直後に確かめられた。
- `move` に複数の選択肢を並べられ、1つでも通らなければ記録が変わらない。

気になった点：
- `score` の見込みは「ゲーム終了時の能力は含まない」ため、sc05・12・06 の44点が入らず、自分の見込みが低く出る。含めた値も並べてほしい。
- `move` に並べるとき、選択肢が1つしかない段（臨時ワーカーが0のときの `temp:0`、空きマスが尽きたときの `done`）は省かれ、付けると全体が失敗する。逆に `done` が要る場合もある（建築・通常で1軒だけ建て、ほかに空きマスがあるとき）。先に `show` で確かめるしかなかった。
- 手番でアクションを済ませた後、続けて別のアクションを `move` すると「選択肢にない指定である：act:…」とだけ出る。「この手番のアクションは済んでいる」と出ると分かりやすい。
- `show`／`wait` の既定の出力が長い（アクションボード10行の説明が毎回出る）。置かれているスペースだけを出す短い形式がほしい（自分でフィルターを書いた）。
- 計画都市の形は軸座標の文字列だけなので、自分の盤面のどこに当てはまるか（回転6通り）を手計算した。「あと何が足りないか」の表示があると助かる。
- 終局時、他の席の襲撃の宣言を待つ間の `wait` は問題なく「ゲーム終了」を返した。

## ゲーム1の知見の検証
役に立った：
- 「建物の数と種類が最大の差」「通常ワーカー10人＋役所3軒」「インフラ12と超過」「特別市民の枚数」「聖女＋sc13 が強い」はそのまま当てはまり、方針の柱にした。
- 「占有型は最初の手で押さえる」（福祉・建築最上位）、「sc05 が強い」（場に出た次の手番でインフラ12にして取った）、「自然公園は空きタイルだけ」（最後に空きタイルで組を作って8点）、「最終ラウンドは使い切り」「序盤は得点0でもエンジン」。
- 「`score` で見込みを見る」「ノートを付ける」。

当てはまらなかった・修正が要る：
- 「輸出で金を作る」：今回は金が余り資材が足りなかった（金生産を 20→43 に上げたため）。輸出は一度も使わず、輸入と文明カード（045・058・033・029）で資材を作った。金と資材のどちらが足りないかは生産力しだい。
- 「襲撃は中盤以降は守る」：守らないほうが得だった（-15点で済み、砦・教練の費用を建物に回せた）。
- 「sc07 が強い」：山岳に建てる数が少なく取らなかった。場の特別市民の価値は盤面とキャラクターで変わる。
- 追加：ボーナスタイル6・8 のパス時得点は合計16点ずつ出ており、ゲーム1の知見より重い。パスの順番は「次の手番順」だけでなく「タイルの取り合い」として考える。
