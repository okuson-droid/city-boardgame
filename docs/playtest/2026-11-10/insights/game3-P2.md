## 3. 強い・弱い
強い：
- **学者（評価：強い。ただしカード運と金のエンジンに依存）**。強み：準備の2枚で初手から選択肢が広い。3枚ごとの選択は「インフラ1（福祉通常1回＝ワーカー1＋資材1相当）／土地タイル1（資材2相当、水場なら海の幸で＋金4）／臨時ワーカー1（資材4相当）」で、26枚で8回＝ワーカー約6〜8人分。インフラ12の後も超過2点として腐らない。弱み：R1〜R2 は金24では2〜3枚しか出せず、効果が出るのは3枚目から。カードの中身（金・資材を返すカード）を引けないと失速する。資材を増やす能力がなく、建物は09と無料建設のカード（095・120・118）に頼った。軍事には何も寄与しない。聖女（特別市民2枚確定）ほど安定はしないが、03 や大学と噛み合えば同等以上。
- 特別市民03、09（無料建設）、普及最上位＋大学3軒（カード1枚 -5金）。

弱い・使いにくい：

## 4. ルールの穴・分かりにくい箇所・バランス
- 3局続けて上位が200点超（213・208）。特別市民03 は1枚で43点、聖女・芸術家・学者のどれでも突出する。獲得時の点か1枚2点のどちらかで足りる。
- 学者の「3枚ごと」は普及最上位・上位と重なると1アクションで1〜2回発動する。R3 は1ラウンドに3回。強いが、金の出るカードがないと回らないので運の幅が大きい。
- 059土地転がしは空きタイル4種類で金24（実質コスト6）。098学資は学術タグの多さ（文学・美術の本がすべて学術）で金14〜。金の戻るカードが重なるとカードが実質無料になる。
- 特別市民11（任意のアクションの効果）で P1 は福祉最上位を毎ラウンド写し、さらに福祉の通常・上位も取って、福祉の3スペースを1人で使い切った。他の席が超過点を取れない。
- 文明カードの土地タイル（008植林・064地均し）は地形と違うマスにも置ける（選択肢に「地形と異なる」と出る）。特別市民06「水場に建てた建物」がマスの地形かタイルの種類か、表示からは分からない。
- 029/032 系の「美術タグ1につき1点」などで、カード固有の「1点」は終了時（文化・学術）に入り、プレイ時の点には含まれない。show の「1点」がいつ入るのか分かりにくい。
- 最終ラウンドのパスでも次のボーナスタイルを選ばされる（意味がない）。
- 襲撃の防衛失敗はラウンド数×1点だけなので、軍事0〜1なら宣言の選択肢は「宣言しない」1つだけ。選択を求めずに自動で処理してよい。

## 5. 対話プレイ用コマンドの使い勝手
- 良い：`--brief`、`score` の見込みと出どころ別の内訳、`move` の複数指定、失敗時に何個目で止まったかの表示。選択肢のラベルにコスト（割引後）が出るのは便利。
- `wait --brief` でも1回の出力が長い（アクションボード・共有の場・選択肢で100行超）。自分で grep して絞った。「前回からの差分だけ」「自分の資源とワーカーだけ」の出力があると楽。
- `wait --board` を grep で絞ると行が二重に出ることがあった（選択肢や他のプレイヤーの行が2回ずつ）。`--board` 付きで同じ節が2度出ているように見える。
- `move` の成功時、資源の増減は「選択の増減」に出るが、複数の手を並べると途中の増減を見落としやすい。最後に資源・ワーカー・得点トラックの1行要約がほしい。
- 臨時ワーカーが0のとき `temp:0` を書くと失敗する（知見どおり）。逆に臨時があるときは必ず要るので、毎回 show で確かめる必要がある。`temp:0` を「あれば通常だけ」の意味で常に受け付けると楽。
- 終局前の `score` は「残った金」が次の収入後の値に見える箇所があった（最終は金6で終えたが同点判定は43）。最終の収入が入る仕様なら説明がほしい。
- 学者の「3枚ごと」の残り回数（次の発動まであと何枚）が show に出ない。プレイ済みの枚数から自分で数えた。
