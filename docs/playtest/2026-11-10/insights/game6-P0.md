## 2. 100点に届いた。何が効いたか／なぜ1位に届かなかったか
**効いたこと**
- **R1 から軍事路線を始められた**：輸出で金を作り（資材3→金15）、砦2軒（初期のA5＋B3）にして教練最上位（金9→トークン8、Lv3→6、Lv6の報酬で資材3）。R1 のうちに遠征最上位を使えて4点＋土地2枚。R3 に Lv10 に達した後は遠征最上位がトークン0で「2点×2＋土地2枚」
- **特別市民02**（最上位のアクションごとに2点）：9回で18点。英雄は教練・遠征の最上位を毎ラウンド使うので相性がよい
- **特別市民01＋強行軍**：遠征・襲撃の撃退・開拓・森の小屋の土地を森林で置いて9枚・18点。強行軍（金5）で遠征の土地タイルを地形と違う種類にでき、自然公園の2枚組と3枚組（8点）も作れた
- **軍事Lv12 の後の教練の超過**：砦3軒なら1段にトークン1個なので、教練最上位は「金9で6点」（＋特別市民02 の2点）。教練通常も「金3で2点」
- 撃退は5回とも無料（英雄で10点＋土地・資材・金）。R4 の撃退報酬「土地タイル4枚」は森林に置いて特別市民01 の6点
- 最終ラウンドに資材4→臨時ワーカーを5回使い、不要なカードと残ったトークン・金を資材に替えて行動を倍にした（研究最上位・遠征通常・教練通常・開拓通常・普及通常で約16点）

**1位に届かなかった原因（約50点差）**
- **通常ワーカーが5〜6人のまま**：最上位を1回使うと2人消えるので、5人では1ラウンドに最上位2回＋1手しかできない。住宅と移住に手が回らず、終了時の「通常ワーカー×役所3軒」は12点（P1 は10人で20点）。構造的な弱点（英雄の能力は行動数を増やさない）と、R2〜R3 に住宅・移住を後回しにした判断の両方
- **インフラを捨てた**（最終5）：P1 はインフラの超過だけで26点、インフラ4・8・12 の特別市民も取った。福祉の3スペースは毎ラウンド P1・P2 に先に取られた。R1〜R2 に福祉を1回でも入れるべきだった
- **カードが少ない**：プレイ7枚（P1 16枚・P2 21枚）。文化・学術8点（相手24・31）。手札のカードは金10前後で1〜2点のものが多く、普及の枠もワーカーも足りなかった
- 特別な市民カード2枚（P1 は7枚）。インフラ由来の特別市民を取れなかったのが大きい
- 最終ラウンドの普及最上位を P2 に先に取られた（最初の手で押さえるべきだった）。終了時に金44 が残った（最終の撃退で金15と最終の収入）

## 3. 強い路線・カード・アクション、弱いもの
- **英雄の評価：強い点の生み方だが、終了時の得点が弱く単独では1位に届かない（今回165点・3位、ゲーム3は213点・1位）**

  - 弱み：初期の土地が1枚だけ（ボーナスタイル1で補った）。資材と行動数を増やす手段がない。最上位を2回使うとワーカーが尽き、住宅・移住・福祉・普及に回らない。建物・ワーカー・カードの終了時の得点で相手に負ける
