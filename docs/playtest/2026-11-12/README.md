## 足りなかったもの・要らなかったもの（打ち手の報告と記録から）

1. ドラフトで個人ボードの地図を見る方法が指示書になく、P0（R1）はリポジトリの `src/data/board_*.json` を直接読んだ（公開データであり非公開情報の漏れはない）。`show --board` か `--only board` の案内が要る。
2. `plan --set` を日本語名で書いて失敗した（P0 R4）。書ける形はエラーに出るが、`--help` と指示書に例が少ない。特別市民の専用スペース（11 の写しなど）を狙いに書けない（P1）。
3. 下見は研究・カードを引く手の手前で止まるため、研究の比較には使えない（P1）。止まった先の選択肢も見たい・全選択肢の比較が欲しい（P0）。後者は指示書 8 の「選択肢ごとの見込みの増減」に当たり、見送った項目である。
4. 第4ラウンドの打ち手が、第5ラウンドの最初の選択（ボーナスタイル1 の土地タイル）を残して終えた。`wait --round 4` がラウンド開始の自動処理の後に「終わった」を返すためで、次の打ち手が引き継いだ。
5. 注意の型にない失点：平原の空きタイルがなく大学を森林に建てて地形の3点を逃した（P2 R2）、学術の追加能力でのプレイは普及の割引が効かない（P2）。
6. `score` は量が多い（P0）。

## 判断の要るところ

- トークン量は条件（ゲーム8を上回らない）を、キャッシュの読み込み・作成・出力では満たした。道具の呼び出しは P2 が上回った。CLAUDE.md の縮小の効果が混ざっているため、新しい機能の分だけを測るなら、CLAUDE.md を同じにした対局か、ゲーム8と同じデータでの対局が要る。
