# P1 聖女 ノート（R4 終了時）
## 計画（R5・最終）
1. 土地→建物：開拓・最上位（4枚、平原優先で住宅+1点）→11で建築・最上位を写す（4軒、+2点）→09で無料建設。先を越されたら開拓・上位／建築・上位。
2. 住宅を増やし移住で通常ワーカーを増やす（いま8人・上限8、住宅6）。住宅10で上限10→10人目で聖女の特別市民。移住・最上位（+2点）。
3. 残りは福祉・通常（インフラ超過1段2点、資材1）。最後に金・資材・手札を使い切る（資材4→臨時、手札→資材）。
## 方針・発見
- 11は占有済みのスペースや未解放の最上位も写せる（R4で建築・最上位を写した）。
- 開拓は土地1枚につき資材2（最上位で全体-2）。資材を先に用意する。
- ボーナスタイル10（インフラ+1＝超過で2点）を取った。17で毎ラウンド臨時+1。
- 公開中の12（住宅コスト資材-1・住宅1つ1点）は取り方を確認する。
- 襲撃は014で防衛した。R5の襲撃も確認（トークン0）。
- 手札：046（大学2軒で金16）・021・099・079・074・085（種類4×金4）・080・028。普及の手が空けば金を回す。
- 次の初手：手番順を確認し、開拓・最上位を先に取る。
