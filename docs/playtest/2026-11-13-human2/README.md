## Fable の誤り

- インフラ Lv8 で特別な市民カードが出ると思い込み、福祉・最上位に資材7を払った（この版の Lv8 はカード1枚）。到達報酬を1段ずつ確かめなかった。
- 序盤から自然公園と計画都市の形を見ていなかった。

## 運用上の観察

- 打ち手は `ref` の出力を grep で1回絞った（インフラの到達報酬を探すため）。到達報酬の表を `ref` に出してほしいという要望が出た。
- ノートの上限 1.5KB はバイト数で数えるため、日本語では約500字しか入らない（R2 の打ち手）。
- 人の手番を待つ間も `online wait` の1回ずつの呼び出しで止まらずに進んだ（シェルのループは使わせなかった）。
