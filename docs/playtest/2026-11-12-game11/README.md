## 運用上の観察

- 15人のうち多くが、指示書で禁じた自作の絞り込み（`sed`・`grep`・`head`・`tail`）を `wait` の出力に使い、自分で報告した。
- `wait` の既定の時間切れ（300秒）が、打ち手の道具の上限（約120秒）より長い。待つ間に道具側で打ち切られ、裏に回った出力を読み直す例が4人あった（P0R5・P1R3・P2R3・P2R5）。
- 建築・上位／最上位の軽減を「1軒ごと」と読み違えた例が2席であった（P0R5・P2R3）。knowledge-play.md の落とし穴に書いてあるが、ref の効果文（「コストを金2・資材2軽減する」）からは読めない。
- ラウンドの最初の選択（捨てるカード）が次の打ち手に回った例が1回あった（通算6回）。
