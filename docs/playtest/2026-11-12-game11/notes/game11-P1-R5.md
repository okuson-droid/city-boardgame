# P1 ノート（R4 終了）精霊使い・タイル2
## R5（最終）の計画（手番は先頭。金55 資材9 通常6 トークン1）
資材とワーカーの両方が制約。輸入せず 金5→資材1 で足し（計20前後）、使い切る。
1. 初手 開拓・最上位（4枚、資材-2）。代わり：開拓・上位
2. 開拓・上位（3枚、-1）
3. 開拓・通常×2（共有）。資材が足りなければ1回を福祉・通常に
- 開拓・通常と教練・上位（襲撃 -5点を防ぐ）を dry-run で比べる
## 置くマス
- 森林タイル＝3点。森林の地形（資材2）：A1・C7・C8・D7
- C4 に山岳（チップの隣で+2、資材2）
- 他の地形に森林は資材3（C5・D4・B7・E5・F5）
- 置けるのは置いたタイルの隣。同じアクションの中で広げられる
## 方針
- 建物は建てない（05 は役所3だけ）
## 気づき
- マスボーナスの特別市民は公開中の4枚から選べる（A8 で 20）
- 福祉・通常を先に打ち、開拓・最上位を P2 に取られた
- 同じボーナスタイルは続けて持てない
