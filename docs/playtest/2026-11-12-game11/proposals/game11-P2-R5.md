# P2 R5 効率化
## 無駄
- resume 約12KB。候補キャラクター・全建物・襲撃の効果文は不要。
- wait が毎回、局面と全選択肢を返す。時間切れの呼び直し4回。
- 内訳・変換・上昇回数で move が計3回増えた。
## 変更案
1. resume --brief：局面・自分・狙いだけ。
2. wait は出来事と狙いの変化だけ返し、自分の番まで待つ。
3. score に区切りまでの差（商店1軒で経済+4 など）を1行。
## 自分で
- temp:0・convert:0・count:0 を最初から並べる。
- 全員パス後は end と次の行動を1回に連ねる。
- R5の最初に score の内訳で0軒の建物を確かめる。
