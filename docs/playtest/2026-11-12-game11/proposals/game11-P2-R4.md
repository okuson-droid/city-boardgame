# P2 R4 効率化の案
## 無駄
- resume が全アクション・候補キャラ7人・襲撃・建物表を毎回出す
- 手番ごとに end と wait を別に呼び、wait が同じ選択肢30行を8回出す
- 開拓で内訳・枚数・マスを1段ずつ4回呼んだ
## 変更案
1. resume：2ラウンド目以降は局面・自分・手札だけ。表は ref へ
2. `move --wait`：end して次の番まで待ち、出来事と変わった選択肢・狙いだけ返す
3. アクション選択時に先の選択（内訳・枚数・マスとコスト）を1回で出す
## 自分
- アクションは内訳・マスまで id を並べ1回で打つ
- 計画前に建物数を確かめる
