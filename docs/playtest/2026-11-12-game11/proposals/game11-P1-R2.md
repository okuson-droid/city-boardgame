# P1 R2 効率化の案
## 無駄
- wait 5回とも局面の全文（選べない理由 約10行・他席・計画都市）が出た。大半が同じ
- resume に ref 全文が付き、R2 では既読
- 次の段の書式が分からず、1手番を2〜3回の move に分けた
## 変更案
1. wait の既定を出来事・狙い・自分1行・選択肢だけにし、選べない理由は --why
2. resume は R2 以降 ref を省く
3. 選択肢に次の段の書式を添える（福祉・最上位 count:0|1|2、輸入 temp:n count:n、開拓 count:n tile:マス:種類）
## 自分で
- 自然公園は開拓の時点で dry-run する
- 占有型（福祉・輸入）を先、共有を後
- 到達報酬の臨時・手札を計画に数える
