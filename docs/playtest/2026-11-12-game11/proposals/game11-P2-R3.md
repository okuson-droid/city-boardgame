# P2 R3 効率化の案
## 無駄
- 建築・最上位の軽減を1軒ごとと誤読、資材1で入り住宅1軒で自動確定。建築・通常を打ち直した
- resume が効果文の全文（約9KB）を出した
- wait が120秒で切れ4回呼び直し。plan の書き方で1回失敗
## 変更案
1. 建築：権利を残して自動確定する前に「軽減は合計。いま建てられる最大N軒」と注意
2. resume：R2以降はドラフト候補・効果文を省く（ref で引く）
3. wait：番が来たら出来事・要約・選べる手だけ。選べない理由は1行
## 自分
- 建築前に dry-run で合計コストを見て資材を買う
- wait は長い timeout と --only events,options
- temp:N まで1回の move にまとめる
