# P0 R4 効率化の案
## 無駄だった場面
- 建築の ID を推測して下見を3回外した（正しくは build:house:E4）。
- 開拓・建築の下見が選択待ちで止まり、呼び直した。
- 資材2のまま建築に入り2軒目を建てられず、手番を余分に使い移住を逃した。
- resume が長い（候補キャラクター・全アクション文）。
## 変更案
1. 下見が選択待ちで止まったら、残る選択肢の ID を1行で出す。
2. 建築を選ぶ前に「注意：資材が足りず N 軒しか建てられない」を出す。
3. resume の R2 以降は候補キャラクターを省く。指示書に ID の書式を1行足す。
## 自分で変えること
- 建築の前に資材を数え、変換を同じ move の先頭に入れる。
- wait は --only options を付ける。
