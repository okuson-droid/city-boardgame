# P1 R5 効率化
## 無駄
- resume の ref 全文（ドラフト候補・全襲撃・全建物）は R5 に不要
- 行動の頭だけの dry-run は「見込み0」で2回無駄
- タイルの書式探しに1回、wait の時間切れで数回
## 変更案
1. resume：R2以降は候補・未使用の文を省き、置けるマスと資材の表を出す
2. dry-run：止まった所の選択肢 ID を出す。見込みに今ラウンドの襲撃の失点を含める
3. 定石に最終ラウンドの単価表（福祉超過2点/資材1、タイル2.5/資材2〜3、教練・上位5点/金6）
## 自分
- マスまで書いた手順だけ dry-run
- move と wait を1回につなぐ（--timeout 100）
- 最初に score の内訳で単価を出す
