# P0 R5 効率化の案
## 無駄だった場面
- 下見が「選択肢にない」で止まるたび ID を当て推量した。8回。
- 建築・最上位の軽減を1軒ごとと誤解し、下見3回と実際の手2回で確かめた。
- wait が道具の120秒で打ち切られ、裏に回った出力を読み直した。resume の R1〜R4 の履歴も不要だった。
## 変更案
1. move --dry-run が止まったら、その時点の選択肢の ID 一覧と「払えない（合計・所持）」を出す。
2. ref の建築の文に「軽減は1回の建築で1度」と書く。指示書に ID の型（tile:<マス>:plains|water|…、build:camp、内訳は臨時があるときだけ temp:N）を1行で載せる。
3. resume は最終ラウンドでは履歴を省き、wait の既定を100秒にする。

- 最終ラウンドは最初に「ワーカー数・金・資材」の表を作り、sc:11 を必ず使う順に並べる。
- 建築の前に金→資材。
