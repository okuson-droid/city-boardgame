作成日：2026-11-06
状態：取り込み済み（53枚）。保留25枚はユーザーの決定を待つ。
準拠するルール：rules.md v0.8

## 0. 方針

- ユーザーから受け取った `文明カード一覧（120枚）.xlsx`（以下「一覧」）のうち、既存の 001〜042（`design/文明カード一覧_sample.md` 由来）に当たるカードを除き、残りを `src/data/cards_civilization.json` の末尾に加えた。
- 一覧の番号は既存の識別子と一致しない（例：一覧 018「建築学」が既存 001）。既存の識別子は変えず、加えるカードには 043 から連番を振った。対応は下の表に記す。
- 既存のカードとの対応は効果の文言で取った。一覧の名称・コスト・タグ・文言が既存と食い違うものは 3 節に列挙し、既存のカードは変更していない。
- 加えたカードは名称・コスト・タグ・文言を一覧のまま持つ。文言の「プレイ時：」は既存のカードに合わせて省き、「常時：」は残す。プレイ条件・効果適用条件・固有得点（1点）は既存と同じく仮置きとする（`provisionalFields`）。
- 効果スクリプトは既存の命令セット（docs/effect-commands.md）に次の拡張を加えて書いた。いずれも既存のカードの動作を変えない。
  - `raise` の `amount` に「指標 n につき m」を書けるようにした（衛生学・戦術学・民兵・役所仕事・住民の声）。
  - 指標 `buildingTypes`（建設済みの建物の種類の数）と `freeLandTerrains`（建物のない土地タイルの地形の種類の数）を加えた。
  - `on` の `actionExecuted` に絞り込み `action`（アクションの種類）を加えた（開発サイクル）。
  - `playCard` に `upTo` を加えた。真のとき、プレイできるカードがあっても「プレイを終える」（`done`）を選べる（「〜枚までプレイする」「プレイできる」「プレイしてもよい」）。
- 一覧のうち、rules.md に定めがなく合法手・得点に影響する解釈を要するカードは加えず、4 節に保留として列挙した。
