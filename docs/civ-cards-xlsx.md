# 文明カード一覧（120枚）.xlsx の取り込み

作成日：2026-11-06
状態：取り込み済み。一覧の120枚すべてを収録した（既存42枚を一覧に合わせて改め、78枚を 043〜120 として加えた）。保留はない。
準拠するルール：rules.md v0.8

## 0. 方針

- ユーザーから受け取った `文明カード一覧（120枚）.xlsx`（以下「一覧」）のうち、既存の 001〜042（`design/文明カード一覧_sample.md` 由来）に当たるカードを除き、残りを `src/data/cards_civilization.json` の末尾に加えた。
- 一覧の番号は既存の識別子と一致しない（例：一覧 018「建築学」が既存 001）。既存の識別子は変えず、加えるカードには 043 から連番を振った。対応は下の表に記す。
- 既存のカードとの対応は効果の文言で取った。既存の42枚は、名称・コスト・タグ・文言を一覧に合わせて改めた（ユーザー決定 2026-11-06、3 節）。
- 文明カードの正は `src/data/cards_civilization.json` であり、`npm run import:design` は文明カードを `design/文明カード一覧_sample.md` から取り込み直さない（古い版に戻るため）。
- 加えたカードは名称・コスト・タグ・文言を一覧のまま持つ。文言の「プレイ時：」は既存のカードに合わせて省き、「常時：」は残す。プレイ条件・効果適用条件・固有得点（1点）は既存と同じく仮置きとする（`provisionalFields`）。
- 効果スクリプトは既存の命令セット（docs/effect-commands.md）に次の拡張を加えて書いた。いずれも既存のカードの動作を変えない。
  - `raise` の `amount` に「指標 n につき m」を書けるようにした（衛生学・戦術学・民兵・役所仕事・住民の声）。
  - 指標 `buildingTypes`（建設済みの建物の種類の数）と `freeLandTerrains`（建物のない土地タイルの地形の種類の数）を加えた。
  - `on` の `actionExecuted` に絞り込み `action`（アクションの種類）を加えた（開発サイクル）。
  - 指標 `tagsOf:<分類>`（プレイ済みの文明カードのうち、その分類のタグを持つ枚数。プレイ中の自身を含む。ユーザー決定 2026-11-06）を加えた。「所持している〇〇タグ」「〇〇タグがある」に使う。
  - `on` の `cardPlayed` に絞り込み `tags`（いずれかの分類を持つ）を加えた（018 知識の泉）。
  - `playCard` に `upTo` を加えた。真のとき、プレイできるカードがあっても「プレイを終える」（`done`）を選べる（「〜枚までプレイする」「プレイできる」「プレイしてもよい」）。
- カードの効果が rules.md と食い違う場合は、カードの効果を優先する（ユーザー決定 2026-11-06）。
- 一覧のうち、rules.md に定めがなく合法手・得点に影響する解釈を要するカードは加えず、4 節に保留として列挙した。

42枚すべての名称を一覧の名称にし、`provisionalFields` から `name` を外した。効果スクリプトは次のとおり改めた。

- 018：絞り込みを「学術」から「音楽・文学・美術のいずれか」（`tags`）にした。018 は学術だけを持つため、2026-11-03 の「018 自身のプレイでは引かない」は解釈から外した。
- 019〜042：先頭に「`tagsOf:<文学・美術・音楽>` 1につき1点」を加えた。得点の評価軸は「その他」（17-0-2、仮置き）とする。
- 025：金の生産力「4につき」を「3につき」にした。
- 026：「撃退に必要な軍事力（撃退ライン − 軍事レベル）」を「撃退ライン」にした。撃退ラインはそのラウンドまでの累積値である（034・042 と同じ扱い）。
- 011：文言が「インフラレベル」になったため、「生活レベル」の読み替えを外した。



## 4. 保留を解いたカードの扱い（ユーザー決定 2026-11-06）

006・007・016・017 は「所持しているタグ」の決定（2026-11-06）により保留を解き、096〜099 として加えた。
051・066〜069 は次の決定（2026-11-06）により保留を解き、100〜104 として加えた。

- 051 大規模開拓：地形と同じ種類の土地タイルを、種類ごとに1枚まで、合わせて4枚まで置く。地形と異なる種類は置けない。置く順番は選べる（`placeTiles` の `distinct`・`upTo`）。
- 066 強行軍：遠征報酬の土地タイルは地形と異なる種類も置ける（補正 `expeditionTilesAnyTerrain`）。文明カードの「遠征報酬を獲得する」の土地タイルにも適用する。
- 067 傭兵団：軍事力トークンを払うすべての場面（遠征・教練・襲撃の宣言・フリーアクション）で、トークン1つの代わりに2金を払える。足りない分は金で払い、使ったトークンを何個金に替えるかは支払いの直後に選ぶ（補正 `tokensByGold`、タスク `tokenSwap`）。
- 068 雲隠れ：襲撃の宣言で「処理を行わない」（`raid:skip`）を選べる。選ぶと、そのラウンドの自分の襲撃の処理をすべて行わない（補正 `skipRaid`）。
- 069 特別任務：遠征アクションで同じ報酬を選べる回数を、通常・上位は2回まで、最上位は3回までにする。選択数（6-3-6-6）は変えない（補正 `expeditionSameReward`）。

残りの16枚は、Claude の推しの解釈をユーザーが承認した（2026-11-06）。カードの効果が rules.md に優先するという原則に従い、カードに書いてあることはそのとおりに、書いていないことは rules.md のとおりにする。

- 003 発明王：普及アクションの処理（途中で起きた効果を含む）をすべて終えた後に1枚引く。引いたカードはその普及ではプレイできない。写した普及も数える（出来事 `actionFinished`）。
- 020 温故知新・021 学術評価：「プレイ済みの文明カード」はプレイ中の自身を含む。
- 071 名誉ある犠牲：防衛失敗のとき、基本得点と襲撃カードの点の減少を受けない。金・資材などの損失は受ける（補正 `noRaidPointLoss`）。調整案（2026-11-08、ユーザー決定 2026-11-10）で「防衛成功の度に1点」に変えた。
- 080 兵法：手札から0〜2枚（調整案 2026-11-08 で0〜3枚に変えた）を捨て、捨てた枚数だけ軍事レベルを上げる。12 を超えた分の得点はない（命令 `discardRaise`）。
- 081 関税：自分を含むいずれかのプレイヤーが輸入アクションを実行する度に2金。写した輸入も数える（絞り込み `anyPlayer`）。
- 083 建設業：住宅以外の建物を建て方を問わず1軒建てる度に2金（絞り込み `exceptBuilding`）。調整案（2026-11-08）で住宅1軒ごとの1金を加えた。
- 101 注文住宅：1回のアクションの処理中（途中で起きた効果を含む）に住宅を2軒以上建てたら、アクションを終えた時に臨時ワーカー1人。1回のアクションにつき1回。アクションの外で建てた住宅は数えない（出来事 `actionFinished`、絞り込み `builtDuring`）。
- 102 公務：インフラレベルが実際に1上がる度に1資材。上限で上がらなかった分は得ない（出来事 `trackRaised`）。
- 103 開拓小屋：1回の建築アクションで建てた建物が住宅1軒だけなら、アクションを終えた時に土地タイルを1枚、地形と同じ種類で置く。
- 109 山小屋・115 森の小屋・117 平屋・118 水車小屋：土地タイルはその地形のマスにだけ同じ種類で置く（4-2-2、`placeTiles` の `onTerrain`）。住宅は任意で、置いたタイルの上にも建てられる。
- 111 繁栄：先に住宅を建て、その住宅を含めて1軒につき1点（命令 `later`）。
- 113 移動住宅：カードの上の住宅は盤面にない住宅とし、建物の数・住宅の数・住宅の上限・建設した時の効果に数え、計画都市・自然公園・建物のない土地・地形ごとの建物の数には数えない（命令 `buildOnCard`、`PlayerState.cardHouses`）。
