# 公開ページのチューナー（案A）

ゲームと同じ公開ページ（GitHub Pages）からデータを編集し、GitHub に保存する仕組みと手順を記す（ユーザー決定 2026-11-04）。
手元の開発サーバー（`npm run tuner`）による編集と書き出しも引き続き使える。

## 仕組み

- チューナーは `https://<user>.github.io/<repo>/tuner/` に置く。ゲームのはじめの画面の「データを編集する（チューナー）」から開ける。
- 編集・検査・調整案の保存と読み込み・試遊は、ブラウザの中だけで行う。試遊ページ（`tuner/play.html`）はオンライン版を出さない（サーバーのデータと食い違うため）。
- 「GitHub に保存」は、GitHub の API で `src/data/` の JSON を1つの commit として保存する（`tools/tuner/github.ts`）。
  - 保存先のブランチの最新の JSON を読み、調整案の変更点（元の値と新しい値）を適用し直す。元の値が食い違う変更点があれば（チューナーを開いた後に誰かが同じ項目を変えた場合）、上書きせずに止める。
  - ブランチは早送りだけで更新する。保存の間に別の commit が入っていれば失敗し、もう一度保存すればよい。
  - commit の本文には変更点の一覧（Markdown）を入れる。claude/tuning_log.md への転記はこれを写せばよい。
- 保存先が main なら、`pages.yml` が検査・ビルドを行い、画面・チューナー・Edge Function を新しいデータで配置し直す（数分かかる）。
- データの更新は進行中の対局に反映しない。オンライン版の部屋は作成時のデータの版（`DATA_VERSION`）を記録し、版が変わった部屋は「データが更新されたため続けられない」と出して止まる。新しい部屋を作り直す。

## 準備（初回だけ）

保存に使うトークンを作る。

1. https://github.com/settings/personal-access-tokens/new を開く（作成画面に直接入る）。
   画面から辿る場合は、右上の自分のアイコン → Settings（リポジトリの Settings ではなく、アカウントの Settings）→ 左の列の一番下の Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token。
2. 次のとおりに設定する。
   - Token name：任意（例：`city-boardgame-tuner`）
   - Expiration：任意（期限が切れたら作り直す）
   - Repository access：**Only select repositories** でこのリポジトリだけを選ぶ
   - Permissions → Repository permissions → **Contents：Read and write**（他は付けない）
3. 作成直後に表示されるトークン（`github_pat_…`）を写す。一度しか表示されない。

## 使い方

1. 公開ページのはじめの画面で「データを編集する（チューナー）」を開く。
2. 「GitHub の設定」を開き、トークンを貼る。リポジトリ（`owner/repo`）とブランチ（`main`）は最初から入っている。設定はそのブラウザにだけ保存される。
3. 値を直し、「試遊」で確かめる。
4. 「GitHub に保存」を押す。表示される「commit を見る」から内容を確かめられる。
5. 数分後に公開ページを読み込み直すと、新しいデータで遊べる。チューナーも読み込み直すと、変更点は0件に戻る。

## 新しいカードを作る

- 文明カード・計画都市カード・自然公園カード・特別な市民カード・キャラクター・襲撃カード・ボーナスタイルは、一覧の上の「新しく作る（選んでいるカードを写す）」で、選んでいるカードを写した新しいカードを加えられる。識別子は自動で次の番号になり、名前には「（写し）」が付く。
- 新しいカードは、名前に加えて文言・分類・効果の説明なども書き換えられる。効果は「効果（命令と引数）」で組み立てる。
- 新しいカードは「このカードを消す」で消せる。元からあるカードは消せない。
- 襲撃カードはラウンド数と、ボーナスタイルは種類数（パラメータ）と枚数がそろっていなければ、検査で止まる。増やすときはパラメータも直す。
- `npm run import:design` で設計文書から取り込み直しても、チューナーで作ったカードは消えない。

## 注意

- トークンを持つ人は誰でもデータを書き換えられる。共用のパソコンでは使い終わったら「トークンを消す」を押す。漏れた場合は GitHub の画面でトークンを削除する。
- 保存先を main 以外のブランチにすると、公開ページには反映されない。確かめてから main に取り込む運用にしたい場合に使う。
- 保存の前の検査は、手元の作業中の写しに対して行う。
